Interval reciprocal QSVT

A linear-system algorithm prepares a state proportional to A−1∣b⟩A^{-1}|b\rangleA−1∣b⟩. In the eigenbasis of a Hermitian AAA, this means multiplying each input amplitude by the reciprocal of its signed eigenvalue. Small eigenvalues need more amplification, so a lower bound on their magnitude is part of the input contract.

QSVT realizes a bounded polynomial transformation through repeated matrix-access circuits and projector phases Gilyén et al., 2019. Here an odd polynomial approaches a scaled reciprocal across a promised signed interval. It applies to more than the special eigenvalues of the spectrum-matched cubic. Related linear-system algorithms and a tutorial on polynomial transformations provide the wider context Childs et al., 2017Martyn et al., 2021.

Implemented scope

The implementation supplies an original reciprocal polynomial, bounded deterministic phase fitting, explicit Hermitian Pauli PREPARE/SELECT/unprepare, a gate-built complex input and complete measured trials. Small circuits have independent numerical reference checks. The polynomial error is analytic; numerical access-angle construction and physical synthesis have separate limits. General non-Hermitian loading, an asymptotically optimal reciprocal compiler and Lean formalization remain planned.

Input, output and motivation¶

Supply real coefficients and Pauli words,

A=∑j=0M−1ajPj,α=∑j∣aj∣,B=A/α,A=\sum_{j=0}^{M-1}a_jP_j,\qquad \alpha=\sum_j|a_j|,\qquad B=A/\alpha,A=j=0∑M−1​aj​Pj​,α=j∑​∣aj​∣,B=A/α,
(1)

together with the promise δ≤∣λ(B)∣≤1\delta\le|\lambda(B)|\le1δ≤∣λ(B)∣≤1. Here MMM counts nonzero terms after equal Pauli words have been combined. This allows positive and negative eigenvalues; AAA must be Hermitian and nonsingular. The normalized condition number is at most 1/δ1/\delta1/δ. The code accepts exact rational or decimal coefficient inputs, and builds gates from their explicit Pauli representation. Dense matrices, eigenvectors and inverse solutions are used only by bounded reference checks.

The default two-data-qubit example is

A=15 II−2 IX−2 ZI−XX,α=20,δ=1/2.A=15\,II-2\,IX-2\,ZI-XX,\qquad\alpha=20,\qquad\delta=1/2.A=15II−2IX−2ZI−XX,α=20,δ=1/2.
(2)

Its four distinct normalized eigenvalues are approximately .53820, .73820, .76180 and .96180; its actual condition number is about 1.787. Qiskit’s rightmost Pauli character acts on q0. Input preparation uses H, S and RY(.63) on q0, followed by RY(.37) on q1 and CX(q0,q1). This constructs a complex entangled input independently of the solution.

The requested output is one conditional Z(q0)Z(q_0)Z(q0​) expectation in the normalized inverse state. Preparing that state does not return all entries of a classical solution or its overall norm. The classical reference solves the same small matrix and compares the same normalized observable.

Actual access, phases and a small circuit¶

PREPARE uses a binary tree of controlled RY rotations to load label amplitudes ∣aj∣/α\sqrt{|a_j|/\alpha}∣aj​∣/α​. SELECT applies the signed Pauli word controlled on its actual label; inverse PREPARE removes the loading. In the exact access model with real coefficients, this complete access is a Hermitian involution whose all-zero-label block is BBB. Numerical probability/sign-phase/angle construction is accounted for separately from that model.

Our scalar convention is

B(x)=(x1−x21−x2−x),D(ϕ)=diag⁡(eiϕ,e−iϕ),V=D(ϕ0)B⋯BD(ϕd).\mathcal B(x)=\begin{pmatrix}x&\sqrt{1-x^2}\\\sqrt{1-x^2}&-x\end{pmatrix},\quad D(\phi)=\operatorname{diag}(e^{i\phi},e^{-i\phi}),\quad V=D(\phi_0)\mathcal B\cdots\mathcal B D(\phi_d).B(x)=(x1−x2​​1−x2​−x​),D(ϕ)=diag(eiϕ,e−iϕ),V=D(ϕ0​)B⋯BD(ϕd​).
(7)

A real-part flag combines the positive and negative phase branches. Its projector operation is exp⁡[iϕ(2Π0−I)Zf]\exp[i\phi(2\Pi_0-I)Z_f]exp[iϕ(2Π0​−I)Zf​], retaining the branch phases. All-zero Pauli labels and flag select the realized real polynomial. Data values are unrestricted by the acceptance test.

The default uses 33 complete PREPARE/SELECT/unprepare calls and 34 projector phases, with both flag Hadamards. The notebook also expands a smaller one-data-qubit example A=3I−XA=3I-XA=3I−X, K=1K=1K=1, so every access operation can be inspected. That coarse example illustrates circuit construction; its lower degree has a correspondingly looser reciprocal bound.

The phase record stores the default phases and exact target Chebyshev coefficients. An original analytical prefix/suffix Jacobian supplies a deterministic SciPy least-squares fit with one initialization and at most 500 function evaluations. The initial Hermitian-signal phases are mapped from the standard signal convention; an initialization near zero would lose Jacobian rank because B2=I\mathcal B^2=IB2=I.

Floating coefficient reconstruction and a 10,001-point grid test provide independent numerical evidence of phase agreement. A separate rational ideal-signal certificate treats every stored binary phase as an exact real number, encloses its complex exponential with a Taylor bound, and propagates the resulting polynomial coefficients exactly. The Chebyshev coefficient one-norm bounds the response error uniformly on [−1,1][-1,1][−1,1], with a telescoping bound for the enclosed phase factors. The frozen default phases have certified uniform error η≤5.476×10−15\eta\le5.476\times10^{-15}η≤5.476×10−15.

Success and size scaling¶

The exact target polynomial has input-independent acceptance lower bound

pmin⁡=c2min⁡(1−Eδ,1)2.p_{\min}=c^2\min\left(\frac{1-E}{\delta},1\right)^2.pmin​=c2min(δ1−E​,1)2.
(9)

For g(x)=[1−(1−x2)m]/xg(x)=[1-(1-x^2)^m]/xg(x)=[1−(1−x2)m]/x on the positive interval, the derivative changes from positive to negative at most once, so the minimum occurs at δ\deltaδ or 1. Oddness gives the same magnitude on the negative interval. Thus the default bound is 1/251/251/25, while the checked default prepared input has acceptance about .08225369. This distinction matters: a favorable small-input probability is not a uniform guarantee for every input.

With MMM nonzero combined input terms, a source circuit uses n+⌈log⁡2M⌉+1n+\lceil\log_2M\rceil+1n+⌈log2​M⌉+1 logical wires: data, labels and a real-part flag. A one-term access needs no label register. At degree ddd, it pays ddd full access calls and d+1d+1d+1 projector phases. Each SELECT contains the controlled nonidentity letters of the actual Pauli words; PREPARE, sign handling and uncomputation are included. Before any compiler cancellation, its complete cost is the sum of input preparation, ddd times PREPARE+SELECT+unprepare, d+1d+1d+1 projector operations, and the final readout. Primitive gate costs depend on the chosen controlled-gate decomposition, so the CSVs report actual lowered circuits rather than treating an access call as free.

Once the relative tail is small at a fixed promised gap, pmin⁡=Θ(1/m)p_{\min}=\Theta(1/m)pmin​=Θ(1/m) while d=Θ(m)d=\Theta(m)d=Θ(m). Worst-input expected access calls per accepted state therefore scale as O(d/pmin⁡)=O(m2)O(d/p_{\min})=O(m^2)O(d/pmin​)=O(m2) for this geometric method. For NNN accepted samples and empty-slot allowance γ\gammaγ, finite-cap access work adds the factor Nlog⁡(N/γ)N\log(N/\gamma)Nlog(N/γ). This includes the decline in acceptance as accuracy increases; degree alone understates the workload.

The scalable active-spin family is

An=3R I−∑i=0n−1Zi−∑i=0n−2XiXi+1,R=2n−1,α=4R.A_n=3R\,I-\sum_{i=0}^{n-1}Z_i-\sum_{i=0}^{n-2}X_iX_{i+1},\quad R=2n-1,\quad\alpha=4R.An​=3RI−i=0∑n−1​Zi​−i=0∑n−2​Xi​Xi+1​,R=2n−1,α=4R.
(10)

Its coefficient norm promises spec⁡(An/α)⊆[1/2,1]\operatorname{spec}(A_n/\alpha)\subseteq[1/2,1]spec(An​/α)⊆[1/2,1]. Every spin participates; local couplings are fixed while the identity coefficient and normalization grow with nnn. There are M=2nM=2nM=2n explicit terms. At fixed gap and requested accuracy, ddd is fixed, logical width grows as n+O(log⁡n)n+O(\log n)n+O(logn), and each access uses O(n)O(n)O(n) controlled rotations/Pauli operations with at most O(log⁡n)O(\log n)O(logn) label controls, plus their control-setting gates. Lowering those controls determines the primitive-time scaling recorded in the width CSV. Total capped work multiplies the complete per-attempt circuit cost by the reported number of attempts. This is a structured circuit-scaling example, not an arbitrary matrix loader or a claim of quantum advantage.

The width CSV records generated circuits for this family. The degree CSV changes accuracy at its fixed n=2n=2n=2 matrix, which differs from the default demonstration. These two CSVs state whether each circuit was simulated. The condition CSV supplies exact target-degree choices from the promised gap; it does not generate or simulate those matrices. A tighter requested gap/accuracy requiring degree above 63 is marked unavailable rather than silently weakening the request.

Circuit generation is bounded to 24 data wires, 48 input terms and odd degree 63. Reference checks allow five data wires and at most 12 total statevector wires. These limits are separate: generating a larger circuit does not validate its behavior by simulation. The bounded physical sweep below covers seven size/conditioning cases; the larger logical width grid remains circuit-only.
