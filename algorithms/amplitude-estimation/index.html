Amplitude estimation

Amplitude estimation turns a flag’s probability into a coherent circuit’s rotation angle. Instead of observing the flag repeatedly, the fundamental algorithm applies controlled amplification steps and estimates their eigenphases Brassard et al., 2002. This is useful when sample preparation or predicate evaluation is expensive and coherent access and inverse access are available. Those operations are explicit parts of the circuit here.

Implemented scope

Standard phase-estimation amplitude estimation, preparation/inverse preparation, a threshold predicate, both reflections, complete controlled powers, final measurements, and an ideal median-confidence contract are implemented. Bounded circuits and their primitive lowering are checked against independent analytic distributions; a separately labeled classical categorical experiment checks median coverage.

The resource section contains a conditional mean-fit surface-code projection. There is no generated Clifford+T synthesis certificate or hardware amplitude-confidence guarantee. Iterative confidence-interval amplitude estimation, a practical application predicate and formal Lean coverage remain planned.

Task and intuition¶

Given a preparation circuit

A∣0⟩=1−a∣ψ0⟩∣0⟩+a∣ψ1⟩∣1⟩,A|0\rangle=\sqrt{1-a}|\psi_0\rangle|0\rangle+ \sqrt a|\psi_1\rangle|1\rangle,A∣0⟩=1−a​∣ψ0​⟩∣0⟩+a​∣ψ1​⟩∣1⟩,
(1)

estimate aaa with a stated absolute error and confidence. Write a=sin⁡2θa=\sin^2\thetaa=sin2θ. Reflection about the prepared state followed by reflection of the good subspace rotates their two-dimensional span by 2θ2\theta2θ. Its two eigenphases are ±θ/π\pm\theta/\pi±θ/π in units of a full turn. Both decode to the same probability through sin⁡2(πϕ)\sin^2(\pi\phi)sin2(πϕ).

Our classical input is an nnn-bit uniform register and threshold kkk; the reversible flag predicate is [x<k][x<k][x<k]. The independent answer is a=k/2na=k/2^na=k/2n. Because that threshold probability is already known, this is an implementation/accounting example with no application advantage. A practical integration, finance or counting problem needs its own reversible predicate and loading cost.

The comparator toggles the flag when the first bit differing from the threshold is zero and the threshold bit is one. At most nnn disjoint prefix terms use X and multi-controlled-X, preserving all data bits with no work register or enumerated truth table. q[0] is the least significant data bit; q[n] is the flag.

Fundamental algorithm and small circuit¶

Let S0=I−2∣0⟩⟨0∣S_0=I-2|0\rangle\langle0|S0​=I−2∣0⟩⟨0∣ and Sg=I−2ΠgS_g=I-2\Pi_gSg​=I−2Πg​. Our iterate is

Q=−AS0A†Sg.Q=-A S_0 A^\dagger S_g.Q=−AS0​A†Sg​.
(2)

Chronologically it applies Sg,A†,S0,AS_g,A^\dagger,S_0,ASg​,A†,S0​,A, and a global minus sign. That sign matters once QQQ is controlled. Dropping it shifts the estimated phase and gives a wrong amplitude; the a=1a=1a=1 test catches this error. S0S_0S0​ is actual X/MCZ/X, with MCZ lowered through H/MCX/H; SgS_gSg​ is Z on the flag.

Prepare A∣0⟩A|0\rangleA∣0⟩, add mmm phase qubits in ∣+⟩|+\rangle∣+⟩, apply controlled Q2jQ^{2^j}Q2j from wire jjj, then inverse QFT and phase measurement. Each power is actual repeated QQQ access, rather than an opaque matrix. For M=2mM=2^mM=2m, output yyy decodes as

a^(y)=sin⁡2(πy/M).\widehat a(y)=\sin^2(\pi y/M).a(y)=sin2(πy/M).
(3)

The default uses two data qubits, threshold one, a flag and four phase qubits: seven logical qubits, a=1/4a=1/4a=1/4, one initial preparation and 15 controlled iterates.

Accuracy, repetitions and classical comparison¶

BHMT Theorem 12 gives single-run success at least p0=8/π2p_0=8/\pi^2p0​=8/π2 for

∣a^−a∣≤2πa(1−a)/M+π2/M2.|\widehat a-a|\le 2\pi\sqrt{a(1-a)}/M+\pi^2/M^2.∣a−a∣≤2πa(1−a)​/M+π2/M2.
(4)

Our answer-independent contract uses ϵM=min⁡(1,π/M+π2/M2)\epsilon_M=\min(1,\pi/M+\pi^2/M^2)ϵM​=min(1,π/M+π2/M2). At m=4m=4m=4 it is 0.234902683, so the example deliberately has coarse precision. The bound can be conservative or trivial at very small mmm.

Run the complete circuit independently an odd number RRR of times and take the median of decoded outcomes. If a majority lies in the interval, its median does too. A binomial majority-tail bound is

∑j=(R+1)/2R(Rj)(1−p0)jp0R−j.\sum_{j=(R+1)/2}^{R}{R\choose j}(1-p_0)^j p_0^{R-j}.j=(R+1)/2∑R​(jR​)(1−p0​)jp0R−j​.
(5)

Requested ideal failure 0.005 needs R=15R=15R=15 under this bound; the value is about 0.00296846. The generator also computes the exact ideal interval-failure probability for this discrete distribution and checks 10,000 classical categorical ensembles at seed 8127. These draw from the exact ideal law; physical circuits are not run.

Classical Bernoulli sampling of the same preparation and flag needs N≥log⁡(2/δ)/(2ϵM2)N\ge\log(2/\delta)/(2\epsilon_M^2)N≥log(2/δ)/(2ϵM2​) shots by Hoeffding. At equal ϵM\epsilon_MϵM​ and δ=0.005\delta=0.005δ=0.005, this is 55 preparations/readouts. The quantum proposal uses 15 full QPE runs including 465 predicate or inverse-predicate calls. Query complexity does not imply a lower compiled cost here, and the known threshold already gives an exact classical shortcut.

For constant success probability, standard amplitude estimation needs O(1/ϵ)O(1/\epsilon)O(1/ϵ) amplification queries and O(n+log⁡(1/ϵ))O(n+\log(1/\epsilon))O(n+log(1/ϵ)) live qubits. This independent median multiplies work by O(log⁡(1/δ))O(\log(1/\delta))O(log(1/δ)). The QFT costs O(m2)O(m^2)O(m2) controlled phases. Each query contains preparation, its inverse and both reflections. Its primitive cost depends on the comparator controls and pinned compiler; the compiled ledger assigns no oracle unit cost.

End-to-end resource analysis¶

The default measured circuit lowers to 2,529 CX, 1,234 RZ, 210 RX, 47 RY, 1,083 T, 813 T-dagger, 504 H, two X and four measurements: 6,426 operations, dependency depth 5,151. Arbitrary rotations remain unsynthesized.

One complete run includes one uncontrolled AAA, 15 controlled AAA, 15 controlled A†A^\daggerA†, both controlled reflections 15 times, all 15 controlled minus signs and the inverse QFT. The 15-run ideal median proposal includes 225 controlled iterates, 465 predicate/inverse calls, 60 phase measurements and 96,390 primitive operations. Data and flag are discarded after phase readout. Fresh zero-state input is assumed; physical initialization/reset faults and classical preparation/decoding/compilation times are unmeasured.

These are conditional mean-fit resource projections from QDK 1.34.0, including surface-code layout and magic-state factories. Its PSSPC formula fits mean fallback work for random angles; it supplies neither a concrete per-angle synthesis certificate nor a runtime-tail guarantee, and abstracts Clifford scheduling. Combining the ideal and physical allowances therefore does not establish a hardware amplitude interval: certified synthesis and its effect on the phase law are still required. Classical comparator construction, compilation, median sorting and external input loading timings are excluded. The separate Grover baseline stays frozen.

Verification and formalization¶

Tests compare every threshold for one through four data bits against an independently specified reversible permutation, including both incoming flag values and endpoint thresholds. They check A∣0⟩A|0\rangleA∣0⟩ against a flagged uniform vector and QQQ against (2∣ψ⟩⟨ψ∣−I)Sg(2|\psi\rangle\langle\psi|-I)S_g(2∣ψ⟩⟨ψ∣−I)Sg​, keeping the exact sign. Several full QPE laws include endpoint phases. Brute-force three-run enumeration independently checks the median-interval formula.

The default distribution agrees with its analytic mixture within 4×10−144\times10^{-14}4×10−14; lowering preserves the prepared state up to a global scalar within 5×10−145\times10^{-14}5×10−14. These bounded numerical checks do not prove every generated circuit. No Lean formalization is integrated; a proof would need an explicit link to this generator and its compiler output.

Data width is capped at 20, phase width at ten and repeated source instructions at 250,000; the shared QPE builder also applies its 200,000 source-instruction cap. These source counts treat each MCX atomically. Primitive export is capped at 250,000 after lowering; controlled-gate compilation can consume extra work before that final guard. Simulation has a separate 12 total-qubit cap. These are rejection limits, not affordability promises for every permitted-size instance. Larger exports/scaling rows carry no simulation claim. Each generation removes its own optional outputs before writing, so disabled estimates or plots cannot leave an older instance’s report behind.

The notebook shares the implementation, reuses outputs above and offers bounded optional live controls. Static publication needs no server. To execute independently, unpack the code bundle, install its package with python -m pip install ., and use the locked environment.
