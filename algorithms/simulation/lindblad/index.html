Noncommuting Lindblad dynamics

This example combines a Hamiltonian rotation with amplitude damping. Their generators do not commute, so alternating exact substeps introduces a controlled splitting approximation. It extends the finite-time damping example with an actual quantum channel circuit for the combined dynamics.

Implementation status

First- and second-order positive-time splitting circuits are implemented and compared with a small independently assembled Liouvillian exponential. Hamiltonian substeps use an exact analytic RY–RZ–RY construction; damping substeps use the checked environment dilation with a fresh reset each time. Original gates, resets, input preparation and final readout are counted. A separate conditional physical-resource study below supplies actual Clifford+T compilation for the fixed 32-step Z task. General Liouvillian access, hardware calibration and formal certificates remain planned.

Model and outputs¶

Set ℏ=1\hbar=1ℏ=1, use one system qubit and

H=0.7X+0.3Z,L=0.8∣0⟩⟨1∣.H=0.7X+0.3Z,\qquad L=\sqrt{0.8}|0\rangle\langle1|.H=0.7X+0.3Z,L=0.8​∣0⟩⟨1∣.

The coefficients and rate have units of inverse time. The time-independent GKSL equation is

ρ˙=L(ρ)=−i[H,ρ]+LρL†−12{L†L,ρ},ρ(t)=etLρ(0).\dot\rho=\mathcal L(\rho)=-i[H,\rho]+L\rho L^\dagger- \tfrac12\{L^\dagger L,\rho\},\qquad \rho(t)=e^{t\mathcal L}\rho(0).ρ˙​=L(ρ)=−i[H,ρ]+LρL†−21​{L†L,ρ},ρ(t)=etLρ(0).
(2)

The fixed task uses t=1t=1t=1 and initial ∣+i⟩|+i\rangle∣+i⟩, prepared with H and S gates. The state output is the system’s reduced density operator before final system readout. An observable output estimates one specified X, Y or Z mean. Each measured export produces a classical trial, with the environment outcome ignored. The code also checks ∣0⟩|0\rangle∣0⟩, ∣1⟩|1\rangle∣1⟩, ∣+⟩|+\rangle∣+⟩ and supplied small mixed density inputs.

GKSL generators are the model context Lindblad, 1976Gorini et al., 1976. This is a single-qubit, single-jump construction; it does not implement arbitrary interacting open-system models.

Exact Hamiltonian access¶

Let

ω=hx2+hz2,θ=atan2⁡(hx,hz).\omega=\sqrt{h_x^2+h_z^2},\qquad\theta=\operatorname{atan2}(h_x,h_z).ω=hx2​+hz2​​,θ=atan2(hx​,hz​).
(3)

Since H=ωRY(θ)ZRY(−θ)H=\omega R_Y(\theta)ZR_Y(-\theta)H=ωRY​(θ)ZRY​(−θ),

UH(s)=e−iHs=RY(θ)RZ(2ωs)RY(−θ).U_H(s)=e^{-iHs}=R_Y(\theta)R_Z(2\omega s)R_Y(-\theta).UH​(s)=e−iHs=RY​(θ)RZ​(2ωs)RY​(−θ).
(4)

The chronological gate order starts with RY(−θ)R_Y(-\theta)RY​(−θ), followed by RZ and then RY(θ)R_Y(\theta)RY​(θ). There is no inner Hamiltonian product-formula approximation. Zero Hamiltonian or zero time skips this substep. The analytic circuit is independently compared with the matrix exponential for positive and negative Hamiltonian coefficients.

Lie and symmetric schedules¶

Write Us(ρ)=UH(s)ρUH(s)†\mathcal U_s(\rho)=U_H(s)\rho U_H(s)^\daggerUs​(ρ)=UH​(s)ρUH​(s)† and let Ds\mathcal D_sDs​ be the finite-time damping channel with rate γ=0.8\gamma=0.8γ=0.8. For δ=t/r\delta=t/rδ=t/r, the circuits implement

F1(t;r)=(Dδ∘Uδ)r,\mathcal F_1(t;r)=\left(\mathcal D_\delta\circ\mathcal U_\delta\right)^r,F1​(t;r)=(Dδ​∘Uδ​)r,
(5)
F2(t;r)=(Uδ/2∘Dδ∘Uδ/2)r.\mathcal F_2(t;r)=\left(\mathcal U_{\delta/2}\circ\mathcal D_\delta\circ\mathcal U_{\delta/2}\right)^r.F2​(t;r)=(Uδ/2​∘Dδ​∘Uδ/2​)r.
(6)

Thus Lie applies H then damping chronologically; Strang applies half H, damping and half H. Every substep duration is nonnegative, and each substep is a valid quantum channel. Lie–Trotter and symmetric Strang splitting provide the algorithmic context Trotter, 1959Strang, 1968. Liouvillian product-formula theory is discussed by Kliesch et al., together with its erratum Kliesch et al., 2011Kliesch et al., 2012; the numerical curves here are implementation evidence.

Each damping step resets the environment to zero, then applies the survival-aware controlled-RY/reverse-CX dilation from the damping example. Resetting the reused environment discards its previous correlations. Keeping the old environment would implement a correlated repeated interaction instead of the intended Markovian composition; a test checks that removing these resets changes the result.

Independent Liouvillian reference¶

The classical reference uses column vectorization:

vec⁡(AρB)=(BT⊗A)vec⁡(ρ).\operatorname{vec}(A\rho B)=(B^T\otimes A)\operatorname{vec}(\rho).vec(AρB)=(BT⊗A)vec(ρ).
(7)

Its 4×44\times44×4 generator is assembled independently as

L=−i(I⊗H−HT⊗I)+L∗⊗L−12[I⊗L†L+(L†L)T⊗I].\mathbf L=-i(I\otimes H-H^T\otimes I)+L^*\otimes L- \tfrac12\left[I\otimes L^\dagger L+(L^\dagger L)^T\otimes I\right].L=−i(I⊗H−HT⊗I)+L∗⊗L−21​[I⊗L†L+(L†L)T⊗I].
(8)

The dense reference is etLvec⁡(ρ0)e^{t\mathbf L}\operatorname{vec}(\rho_0)etLvec(ρ0​), evaluated with SciPy 1.18.1 SciPy developers, n.d.Al-Mohy & Higham, 2009. It assembles the time-scaled generator from γt,hxt,hzt\gamma t,h_xt,h_ztγt,hx​t,hz​t before exponentiation, keeping small finite exposures representable even for large coefficients and short times. Unrepresentable raw matrix entries are rejected. Qiskit DensityMatrix instead evaluates the actual gate/reset circuit and traces the environment. Supplied mixed density matrices initialize this small classical checker; no arbitrary quantum mixed-state loading algorithm is claimed.

Four physically prepared inputs reconstruct the numerical channel matrix. We report selected-input trace distance and the spectral norm of the column-vectorized channel error. The latter is the induced Hilbert–Schmidt 2→22\to22→2 norm; it is distinct from induced trace norm and diamond norm. It is not a worst-case observable-confidence certificate.

The primary Liouvillian paper uses a doubled dissipator D[X](ρ)=2XρX†−{X†X,ρ}D[X](\rho)=2X\rho X^\dagger-\{X^\dagger X,\rho\}D[X](ρ)=2XρX†−{X†X,ρ}, so its XXX corresponds to L/2L/\sqrt2L/2​ in our convention. Constants and norms must be reconciled before using a theorem from that source. Neither a plotted numerical curve nor the uncorrected paper supplies a general classical-simulation or quantum-advantage claim.

Resources and separate errors¶

The measured trial includes named input preparation, all analytic Hamiltonian rotations, every damping dilation, environment reset/discard and X/Y/Z basis changes. The compiler can merge neighboring Hamiltonian half steps, so metadata distinguishes source-level substep calls from actual primitive counts. Depth is a circuit dependency depth, without a physical scheduling model.

Conditional physical-resource study¶

The complete-instrument study contains damping-Z, Lindblad-Z and thermal X/Z: four measured tasks, eight physical profiles and 23 retained Pareto points. Its Lindblad report fixes H=0.7X+0.3ZH=0.7X+0.3ZH=0.7X+0.3Z, damping rate 0.8, t=1t=1t=1, input ∣+i⟩|+i\rangle∣+i⟩, 32 Strang steps and one Z mean. All source resets and final readouts are retained; the environment result is ignored. This covers the stated two-wire trial, with no physical projection of other step counts or interacting models.

Conditional physical assumptions

Protected Pauli-parity/CNOT geometry, tracked Clifford bases and compatible factory/data handoff are assumed Litinski, 2019Horsman et al., 2012. Separate initialization-residual and memory scenarios, independent majority-path readout and controller failure 10-15 per decision remain uncalibrated. Timing assumes 100 ns gates/initialization, 500 ns readout, 1,000 ns code cycles and 10,000 ns controller reaction. This is not a layout or decoder certificate; arbitrary source-level adaptive feedback is outside the supported fixed schedules and reset/T-correction/dispatch macros.

Offline angle/coefficient preparation, synthesis preprocessing and final statistical-processing wall time are excluded from quantum runtime; actual synthesis time is reported separately. Formal synthesis, interface certification and decoder throughput remain unavailable. See the generator, manifest and README for reproduction and complete exclusions. The frozen Grover baseline is unchanged; this separate instrument scenario supplies no matched co-design improvement claim.

python scripts/generate_simulation_lindblad.py --steps 512 --no-sim \

Generation is capped at 4,096 steps and an estimated 60,000 primitive operations. Dense circuit checks stop at 256 steps, validation grids at 16 counts per order, and the 4×44\times44×4 reference at an evolution-scale bound of 100. The quantum model stays at one system plus one reusable environment. General interacting Lindblad methods, additional channels and higher-order dissipative algorithms remain planned until their circuits and contracts are implemented.
