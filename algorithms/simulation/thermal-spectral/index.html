Thermal spectral filtering with retargeted QSP

A spectral filter can suppress high-energy amplitudes without expanding powers of the Hamiltonian into a Pauli-word table. This method applies an exponential-shaped QSP polynomial through the original Hamiltonian’s access circuit. It advances the aggregated Taylor thermal filter to newly generated phases for each Hamiltonian size and inverse temperature. The coefficients used for fitting are classical scalar data; no eigenvectors or matrix exponential are loaded into a gate.

Implementation status

Actual phase generation, PREPARE/SELECT/unprepare access, a real parity selector, Bell preparation and complete measured trials are implemented. The generator supplies bounded gate/reference checks and separate larger circuit-only counts. Analytic/interval bounds cover the declared logical circuit with exact controls and stored binary64 rotation angles. The complete-resource study below supplies actual Clifford+T trials and a separate conditional instrument model for one and two spins. SDK realization and synthesis checks remain numerical; general thermal mixing, hardware validation and formal/Lean proofs remain planned.

Shift the exponential into a bounded signal function¶

Since H/αH/\alphaH/α has spectrum in [−1,1][-1,1][−1,1], let a=βα/2a=\beta\alpha/2a=βα/2 and

F(x)=e−a(x+1),0<F(x)≤1.F(x)=e^{-a(x+1)},\qquad 0<F(x)\le1.F(x)=e−a(x+1),0<F(x)≤1.
(3)

The scalar shift gives F(H/α)=e−β(H+αI)/2F(H/\alpha)=e^{-\beta(H+\alpha I)/2}F(H/α)=e−β(H+αI)/2. It changes preparation success, but cancels when the thermal density is normalized. Shifted QSP imaginary-time primitives provide context Silva et al., 2023; this circuit does not implement that paper’s fragmentation protocol or inherit its resource claims.

A single real QSP polynomial has fixed parity. Split the filter into

C(x)=e−acosh⁡(ax)2,S(x)=−e−asinh⁡(ax)2,C(x)=\frac{e^{-a}\cosh(ax)}2,\qquad S(x)=-\frac{e^{-a}\sinh(ax)}2,C(x)=2e−acosh(ax)​,S(x)=−2e−asinh(ax)​,
(4)

then use a uniform real selector to produce

K(x)=C(x)+S(x)2=F(x)4.K(x)=\frac{C(x)+S(x)}2=\frac{F(x)}4.K(x)=2C(x)+S(x)​=4F(x)​.
(5)

Even and odd degree sequences share their common access calls; one actual controlled access supplies the extra odd degree. The thermal selector has relative phase +1. The retargeted dynamics method uses the same construction with an exact S-dagger relative phase for cosine minus iii sine. The QSP convention and block transformation are specified there Gilyén et al., 2019.

Actual access, fitting and circuit¶

PREPARE loads ∣hj∣/α\sqrt{|h_j|/\alpha}∣hj​∣/α​ through a controlled-RY tree. Indexed Pauli operations and exact Clifford pattern phases implement signed SELECT; unused labels apply identity. PREPARE, SELECT and inverse PREPARE form a Hermitian involution for the named logical gates. Its loaded magnitudes use stored binary64 angles and are independently enclosed by the weight validator.

The floating fitting targets use scaled modified-Bessel coefficients: C0=ive⁡(0,a)/2C_0=\operatorname{ive}(0,a)/2C0​=ive(0,a)/2, even Ck=ive⁡(k,a)C_k=\operatorname{ive}(k,a)Ck​=ive(k,a) and odd Sk=−ive⁡(k,a)S_k=-\operatorname{ive}(k,a)Sk​=−ive(k,a). Bounded symmetric least-squares optimization with an analytic Jacobian generates the phases Dong et al., 2021. Fit convergence and sampled residuals are numerical evidence. A separate validator must accept the resulting stored phases before a circuit is constructed.

Rigorous source contract and realization limits¶

The validator uses explicitly directed Decimal endpoint arithmetic and manual real Taylor enclosures for phase trigonometry and the exponential. It reconstructs the signal polynomial, converts monomials to Chebyshev coefficients using exact binomial factors, and bounds the continuum error by coefficient ℓ1\ell_1ℓ1​ residual plus analytic Taylor remainder Python Software Foundation, 2026. It does not turn a sampled phase-fit grid into a uniform certificate.

Let δe,δo\delta_e,\delta_oδe​,δo​ bound the two real responses, Δa\Delta aΔa be the exact-rational parameter-rounding gap, and www the certified loaded-weight ℓ1\ell_1ℓ1​ error. For the declared logical encoded map,

ϵK≤δe+δo2+∣Δa∣2+aw4.\epsilon_K\le\frac{\delta_e+\delta_o}{2}+\frac{|\Delta a|}{2}+\frac{a w}{4}.ϵK​≤2δe​+δo​​+2∣Δa∣​+4aw​.
(6)

The last term follows from Duhamel’s formula for the two shifted positive exponential contractions. The input normalization and aaa multiplication are accounted separately from the actual PREPARE-angle probabilities. The named logical Cliffords/controls, stored phase angles and Bell H/CX gates define this certified model; Qiskit nested gate definitions are a separate realization.

For the exact target Bell branch, s≥e−2a/4s\ge e^{-2a}/4s≥e−2a/4. If ϵK<s\epsilon_K<sϵK​<s, a conservative perturbed acceptance bound is (s−ϵK)2(s-\epsilon_K)^2(s−ϵK​)2 and a Gibbs trace-distance bound is min⁡(1,2ϵK/s)\min(1,2\epsilon_K/s)min(1,2ϵK​/s). The latter remains valid after unconditioned reference discard. These are conservative source bounds; they can be much looser than the particular-instance numerical acceptance and density error.

SDK nested-control/MCX definitions and compiler-created/merged angles need additional norm bounds. Source/primitive comparisons with phase retained are numerical checks and do not supply those bounds. Rotation synthesis, physical faults and irreversible reset/readout errors require separate models. No mean-fit resource projection or error probability is substituted for a coherent norm certificate.
