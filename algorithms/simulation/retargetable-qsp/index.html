Retargetable complex quantum signal processing

Time evolution changes when the Hamiltonian size, coefficients or simulated time change. The first QSP example freezes phases for αt=4.1\alpha t=4.1αt=4.1; this method generates new phases for each requested normalization-time parameter. It retains explicit PREPARE/SELECT/unprepare access and checks the resulting complex circuit against small independent classical answers.

Implementation status

Bounded numerical phase generation, a separate directed-interval coefficient validator, exact logical signed SELECT, interval PREPARE weight checks and complex selector circuits are implemented. Seven fixed-coupling size/time cases have circuit/reference checks. Circuit-only generation still fits and validates new phases. The complete-resource study below supplies actual Clifford+T measured trials and a separate conditional instrument model for one and two spins. Numerical synthesis and SDK realization premises remain distinct from the logical-source certificate; deterministic evolution and formal/Lean proof remain planned.

Task and intuition¶

The explicit input is a real Pauli list H=∑jhjPjH=\sum_jh_jP_jH=∑j​hj​Pj​. Interpret its supplied binary64 coefficients and time ttt as exact real input numbers, and define the mathematical normalization α=∑j∣hj∣\alpha=\sum_j|h_j|α=∑j​∣hj​∣. The task approximates U=e−iHtU=e^{-iHt}U=e−iHt, or estimates a specified observable after that evolution. Here ℏ=1\hbar=1ℏ=1, the initial state is ∣0n⟩|0^n\rangle∣0n⟩ and the measured observable is Z0Z_0Z0​.

The demonstrated open chain uses fixed local couplings

Hn=∑j=0n−2ZjZj+1+0.7∑j=0n−1Xj,H_n=\sum_{j=0}^{n-2}Z_jZ_{j+1}+0.7\sum_{j=0}^{n-1}X_j,Hn​=j=0∑n−2​Zj​Zj+1​+0.7j=0∑n−1​Xj​,

so αn=(n−1)+0.7n\alpha_n=(n-1)+0.7nαn​=(n−1)+0.7n. Qiskit Pauli labels read the highest wire first; the rightmost letter acts on q0. Hamiltonian coefficients are in the chosen energy unit and time in its inverse.

The displayed 0.7 names the supplied binary64 value, rather than an additional certificate for the exact rational 7/10 or a physical coupling. Converting external decimal coefficients, experimental data or a continuous physical model into these inputs is a separate representation-error allowance. For Pauli inputs, a stated coefficient discrepancy can be bounded by ∥Hinput−Hmodel∥≤∑j∣hjinput−hjmodel∣\|H_{\rm input}-H_{\rm model}\|\le\sum_j|h_j^{\rm input}-h_j^{\rm model}|∥Hinput​−Hmodel​∥≤∑j​∣hjinput​−hjmodel​∣ and charged through the unitary Duhamel bound.

QSP applies one scalar polynomial to every normalized eigenvalue x=E/α∈[−1,1]x=E/\alpha\in[-1,1]x=E/α∈[−1,1]. Changing nnn at fixed couplings changes τ=αt\tau=\alpha tτ=αt, so it changes the desired cosine and sine responses. A frozen sequence for one τ\tauτ cannot implement this input family. PREPARE is a tree of actual RY/control gates loading ∣hj∣/α|h_j|/\alpha∣hj​∣/α approximately. Indexed Pauli operations implement SELECT, and every access unprepares the label register. Negative coefficients use exact named Clifford zero-pattern phases: Z for one label, H–MCX–H for multiple labels, or an explicit ZXZX=−IZXZX=-IZXZX=−I sequence when no label exists. They do not use a binary64 approximation of a π\piπ sign phase. Padded labels apply identity. Interval bounds and realization stages¶

The validator treats the stored binary64 phases as exact real angles. It encloses their sine/cosine values with Taylor polynomials and real Lagrange remainder bounds, propagates the QSP polynomial coefficients using directed decimal arithmetic, then converts power coefficients to Chebyshev coefficients by an exact binomial identity. On [−1,1][-1,1][−1,1], ∣Tk(x)∣≤1|T_k(x)|\le1∣Tk​(x)∣≤1, so the coefficient-residual l1 sum plus the separately enclosed target remainder gives a uniform error upper bound. Authoritative interval endpoints are decimal strings; binary64 summary bounds round outward Python Software Foundation, 2026.

The phase fit’s sampled residual is numerical evidence. Its coefficients, Jacobian and optimizer status do not replace the interval bound. The interval calculation independently encloses the analytic cosine/sine target, including its high-degree remainder; it does not trust SciPy’s floating Bessel values as certified coefficients.

A second interval calculation propagates the actual label-only RY/X PREPARE at its stored angles. If p^j\widehat p_jp​j​ are its probabilities and pj=∣hj∣/αp_j=|h_j|/\alphapj​=∣hj​∣/α, including zero target weight on padded labels,
