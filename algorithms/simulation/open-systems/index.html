Open-system simulation

Motivation and intuition¶

An environment can carry away information and energy, so a reduced system can evolve irreversibly even when the joint circuit is unitary. A dilation makes that interaction explicit; discarding every environment outcome produces the channel. Conditioning on an environment outcome would be a different operation.

This first open-system example implements a finite-time amplitude-damping channel with an actual two-qubit environment dilation. It belongs to the quantum-simulation umbrella. Its circuit, reduced state and observables are checked; general interacting Lindblad algorithms remain planned.

The next Lindblad splitting example adds a noncommuting Hamiltonian with actual first/second-order channel schedules, fresh environments and an independent Liouvillian reference. The absorbing channel on this page remains its separately checked dissipative ingredient.

The interacting Lindblad-chain method adds two-spin ZZ coupling, local X drives and local damping, with a global positive-time palindrome and an independent GKSL matrix check. Its measured energy and reset costs are analyzed in that method article.

Implementation status

The channel uses controlled RY and CX, with gate-based input preparation and a zero-input environment. Tests compare the actual gate circuit’s reduced density operator with an independent Kraus reference. The measured exports include resets, input preparation, basis changes and final measurements. A separate conditional physical-resource study below supplies actual Clifford+T compilation for the fixed default Z task. Hardware calibration, certified synthesis and general Liouvillian access remain unavailable.

Fundamental algorithm and small circuit¶

Environment dilations represent irreversible channels as a larger reversible interaction followed by discarding an environment Stinespring, 1955. Here the construction is explicit. Wire q0 is the system and q1 is the environment. Apply

CRYs→e ⁣(2atan2⁡(p,e−γt/2)),CXe→s.\mathrm{CRY}_{s\to e}\!\left(2\operatorname{atan2}(\sqrt p,e^{-\gamma t/2})\right),\qquad\mathrm{CX}_{e\to s}.CRYs→e​(2atan2(p​,e−γt/2)),CXe→s​.
(3)

This is mathematically the angle 2arcsin⁡p2\arcsin\sqrt p2arcsinp​. Numerically the finite-time builder keeps the survival amplitude e−γt/2e^{-\gamma t/2}e−γt/2 separately, so small coherences remain represented when ppp rounds to one. The independent finite-time reference likewise uses e−γte^{-\gamma t}e−γt populations and e−γt/2e^{-\gamma t/2}e−γt/2 coherences directly. The probability-only API still implements a separately specified ppp.

With the environment in zero, this maps

(4)

No dense channel or Kraus operator is appended as a quantum gate. Before export, controlled rotations are lowered to explicit single-qubit rotations and CX gates.

The environment is traced/discarded for a retained-state output. The measured circuit instead measures both wires and ignores every environment outcome. It never postselects environment zero: conditioning on an environment result would implement a different task. An inverse dilation is not applied, since it would undo the intended system/environment interaction. Each independent trial begins with a freshly reset/prepared environment.

Verification and formalization¶

The classical reference is

Ep(ρ)=K0ρK0†+K1ρK1†,\mathcal E_p(\rho)=K_0\rho K_0^\dagger+K_1\rho K_1^\dagger,Ep​(ρ)=K0​ρK0†​+K1​ρK1†​,
(6)
K0=(1001−p),K1=(0p00).K_0=\begin{pmatrix}1&0\\0&\sqrt{1-p}\end{pmatrix},\qquad K_1=\begin{pmatrix}0&\sqrt p\\0&0\end{pmatrix}.K0​=(10​01−p​​),K1​=(00​p​0​).
(7)

The actual circuit is evaluated with Qiskit Statevector/DensityMatrix and partial trace; the reference is formed independently with NumPy matrices and the finite-time formulas above. Those matrices are classical checks, not the quantum implementation. This particular finite-time dilation has no time-discretization approximation: with exact angles it realizes the stated one-jump channel. The reported residuals reflect floating arithmetic and numerical simulation. Tests include γt=40\gamma t=40γt=40, where ppp rounds to one but the coherence e−20e^{-20}e−20 remains nonzero. Finite floating-angle precision near π\piπ still limits accuracy at extreme times; no arbitrary-precision guarantee is claimed.

Tests cover four gate-prepared inputs at several times, arbitrary small mixed inputs, zero/full damping, the semigroup composition rule, positivity, trace and X/Y/Z means. They also check a two-system entangled input under the separately generated tensor product of two independent channels. Such bounded checks do not establish a general many-body algorithm or formal proof.

End-to-end resource analysis¶

The independent-channel generator uses one environment per system qubit, so width is 2n2n2n and its product channel has linear gate/readout cost at fixed time. That structure excludes interactions. Driven Lindblad splitting adds a step count rrr, fresh environment resets and noncommuting evolution; its current validated model has one system qubit. A larger interacting system needs its own access and accuracy contract, not extrapolation of this channel.

The complete known-input trial explicitly resets system and environment, prepares the named state, applies the dilation and measures both wires. X readout uses H before measurement; Y readout uses S-dagger then H; Z readout uses no basis rotation. The environment is measured in Z and its bit is ignored. Gate counts include these operations and the decomposition of CRY.

The generator has a separate input-preserving access API for a caller-supplied quantum state. It does not reset that system or claim to prepare arbitrary mixed inputs. reset=True requires named prepared inputs, so a reset cannot silently erase an unknown input. A density matrix supplied to the bounded classical checking routine initializes the simulator; it is not a quantum state-loading algorithm.

independent trials. The resource ledger repeats the complete trial counts across that proposal. It is not a joint X/Y/Z tomography or multiple-input/time confidence budget. All settings in the numerical comparison would need their own measurement allocations on a device. An illustrative seeded classical draw from ideal circuit probabilities does not establish that confidence bound.

Channel approximation/representation, coherent synthesis, statistical error and physical faults remain separate. The ideal analytic channel has no time-step approximation; these original logical exports retain continuous-angle gates. A 0.05 observable-error proposal allocates 0.01 to channel bias, 0.01 to synthesis bias and 0.03 to sampling. Statistical failure and total physical-fault probability are separately proposed at 0.005 each. Those allocations do not certify a fault-tolerant circuit. The static shared resource adapter rejects explicit resets; the separate complete-instrument study below accounts for them under its own workload and physical model.

For each fixed rate/time, classical coefficient preparation evaluates exp, sqrt and atan2; the resulting coefficients are reused across trials. Its wall time, classical readout processing, physical reset/discard/readout time, routing, error correction and factories are excluded from these logical counts. No physical-resource improvement or hardware performance is claimed.

Conditional physical-resource study¶

The complete-instrument study computes four measured tasks: this damping-Z trial, the 32-step Lindblad-Z trial and the thermal X/Z trials. It retains eight physical profiles and 23 qubit/time Pareto points across those tasks. The damping report fixes γ=0.8\gamma=0.8γ=0.8, t=1t=1t=1, input ∣+⟩|+\rangle∣+⟩ and Z readout, with system/environment initialization and both final measurements. Environment outcomes remain unconditioned.

The source trial is compiled to an actual Clifford+T trial, including 86 T/T-dagger gates. Qiskit 2.6.2 uses ancilla-free Ross–Selinger synthesis Ross & Selinger, 2014Qiskit contributors, n.d.Qiskit community contributors, n.d.. The sum of numerical per-gate Frobenius errors plus guards is approximately η=7.89×10−5\eta=7.89\times10^{-5}η=7.89×10−5, yielding the proposed unconditional mean-bias allowance 2η2\eta2η. This uses generated sequences and small instrument checks; a mean-fit rotation-count proxy would not supply that evidence. The guard is not a formal interval certificate, and exported QASM omits global phase.

This study assigns failure budgets 0.0025 each to sampling, physical faults and factory availability. Statistical error 0.03 then requires 14,855 complete trials, with no algorithm postselection. The original 13,315-trial logical proposal above retains its separate 0.005 sampling-failure allocation. Both trial ensembles are calculated workloads, not executed hardware experiments. Conditional physical assumptions

The model assumes tracked Clifford frames, protected Pauli bases and compatible magic-port orientation/handoff geometry Litinski, 2019Horsman et al., 2012. It uses separate memory and initialization-residual scenarios, independent majority-of-disjoint-paths readout, 100 ns gates/initialization, 500 ns measurement, 1,000 ns code cycles and 10,000 ns controller reaction with failure 10-15 per decision. These are scenario parameters, not hardware/decoder calibration or a layout certificate. Only fixed source schedules and the stated reset/T-correction and factory/trial dispatch macros are supported.

Offline coefficient generation, circuit/synthesis preprocessing and final statistical-processing wall time are outside quantum runtime; synthesis time is recorded separately. Formal synthesis, interface certification and decoder-throughput validation remain unavailable. The generator, manifest and README record exact sources, budgets and exclusions. This separate serialized scenario leaves the frozen Grover baseline unchanged and supplies no matched co-design comparison.

Run, parameterize and inspect¶

python scripts/generate_simulation_open_systems.py
pytest tests/test_simulation_open_systems.py

The circuit-only independent-channel generator scales by adding one system/environment pair per channel. For example:

python scripts/generate_simulation_open_systems.py --n-system 16 --no-sim \
  --output-dir artifacts/independent-damping-16

Generation stops at 32 system plus 32 environment wires. The public dense-check helpers stay at one system plus one environment; larger generator runs are explicitly marked unvalidated. The independent tensor-product family does not implement interacting Lindblad dynamics. General channels, noncommuting generators, higher-dimensional environments and controlled approximation schemes remain planned until their access circuits and error contracts are implemented.
