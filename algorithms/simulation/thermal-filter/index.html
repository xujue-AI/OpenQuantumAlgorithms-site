Noncommuting thermal filtering

Implementation status

This bounded example implements a noncommuting imaginary-time Taylor filter with actual PREPARE/SELECT/unprepare access. Its conditional purification and reduced thermal state are checked against independent matrix-polynomial and Gibbs references. Full reset/readout attempts and capped retries are counted. Classical Pauli aggregation can be exponential; scalable word-indexed/QSP Gibbs filtering, amplification, certified synthesis and physical resources remain planned.

This method advances beyond the diagonal coefficient loader: the Hamiltonian has noncommuting terms, and the initial reduced system is maximally mixed. No eigenvectors or dense exponential produce a quantum gate. A dense answer serves only as a tiny independent check. Truncated-Taylor LCU and Gibbs-preparation algorithms provide the broader access/normalization context Berry et al., 2015Poulin & Wocjan, 2009Chowdhury & Somma, 2017.

Model and thermal task¶

The example uses one system qubit and

H/E0=0.6Z+0.4X,E0=1,kB=1,β=1.25/E0.H/E_0=0.6Z+0.4X,\qquad E_0=1,\qquad k_B=1,\qquad\beta=1.25/E_0.H/E0​=0.6Z+0.4X,E0​=1,kB​=1,β=1.25/E0​.
(1)

Temperature is T=0.8E0T=0.8E_0T=0.8E0​. Since X and Z do not commute, a Z-basis bitstring does not give the energy. The target is ρβ=e−βH/Tr⁡(e−βH)\rho_\beta=e^{-\beta H}/\operatorname{Tr}(e^{-\beta H})ρβ​=e−βH/Tr(e−βH), or the separately stated thermal means of X, Z and H.

Prepare a Bell pair with an H gate and a CX gate:

∣Φ2⟩=(∣00⟩+∣11⟩)/2.|\Phi_2\rangle=(|00\rangle+|11\rangle)/\sqrt2.∣Φ2​⟩=(∣00⟩+∣11⟩)/2​.
(2)

More generally ∣Φd⟩=d−1/2∑x∣x⟩S∣x⟩R|\Phi_d\rangle=d^{-1/2}\sum_x|x\rangle_S|x\rangle_R∣Φd​⟩=d−1/2∑x​∣x⟩S​∣x⟩R​ has reduced system state I/dI/dI/d. System wires come first, equally sized reference wires next, and the LCU label register last. The default circuit uses one system, one reference and two label qubits. Input and label preparation are actual gates from all-zero wires, with fresh reset instructions in each exported measured attempt.

Imaginary-time polynomial and explicit access¶

For degree K, approximate the filter by

TK(H)=∑k=0K(−βH/2)kk!=∑jbjPj,s=∑j∣bj∣.T_K(H)=\sum_{k=0}^K\frac{(-\beta H/2)^k}{k!}=\sum_j b_jP_j,\qquad s=\sum_j|b_j|.TK​(H)=k=0∑K​k!(−βH/2)k​=j∑​bj​Pj​,s=j∑​∣bj​∣.
(3)

The coefficients are generated by Pauli multiplication, not matrix exponentiation or classical diagonalization. Each Hermitian power uses (HP+PH)/2=HP(HP+PH)/2=HP(HP+PH)/2=HP because P is a polynomial in H. This lets anticommuting Pauli pairs cancel algebraically before floating arithmetic. No tolerance pruning is used. Aggregation still may grow exponentially, and it is not the scalable word-series oracle.

At K=6K=6K=6, the default aggregate contains I, X and Z, with s≈1.7496670s\approx1.7496670s≈1.7496670. PREPARE loads amplitudes ∣bj∣/s\sqrt{|b_j|/s}∣bj​∣/s​ by controlled RY gates. Indexed Pauli operations and coefficient signs implement SELECT; inverse PREPARE is included. Padded labels act as identity. The actual access circuit has zero-label block TK/sT_K/sTK​/s, which tests compare with an independent matrix Taylor recurrence. Every controlled access operation is lowered before export/counting.

Applying this access to the Bell input and accepting only zero labels gives a conditional purification. Tracing out the reference without conditioning gives

ρK=TKTK†Tr⁡(TK†TK),pK=Tr⁡(TK†TK)ds2.\rho_K=\frac{T_KT_K^\dagger}{\operatorname{Tr}(T_K^\dagger T_K)},\qquad p_K=\frac{\operatorname{Tr}(T_K^\dagger T_K)}{d s^2}.ρK​=Tr(TK†​TK​)TK​TK†​​,pK​=ds2Tr(TK†​TK​)​.
(4)

The reference marginal is (TK†TK)T/Tr⁡(TK†TK)(T_K^\dagger T_K)^T/\operatorname{Tr}(T_K^\dagger T_K)(TK†​TK​)T/Tr(TK†​TK​); it must not be confused with the system output. Reference measurements conditioned on a result would change the state task. The full measured-trial circuit instead resets the reference without conditioning and then reads the system in the requested Pauli basis.

Tests also include Y-containing one- and two-qubit Hamiltonians, so imaginary entries, register transposition and Y-readout signs are exercised Qiskit contributors, n.d.SciPy developers, n.d..

Accepted measured trials and oracle costs¶

Default ideal acceptance is about pK=0.4685902p_K=0.4685902pK​=0.4685902. Eight complete attempts suffice for at least one accepted measured output with 99% ideal acceptance confidence. The attempts include fresh system/reference/label resets, Bell preparation, actual access/uncomputation, label measurement, unconditioned reference reset, basis changes and system readout. Every branch runs the whole schedule; failed measured trials are discarded afterward. No early-abort saving or amplitude amplification is claimed.

The default Z attempt lowers to 21 CX, 8 RZ, 7 RY, 6 X, 6 T, 6 T-dagger and 2 H gates, plus 5 resets and 3 measurements. The X attempt has its actual final H-basis change and different lowered counts. Continuous-angle rotations remain unsynthesized. Native T/T-dagger instructions are counted separately from arbitrary rotations; their presence does not certify the rest of the circuit.

Conditioning, synthesis and physical faults¶

Postselection can amplify coherent error. Suppose the coherent Bell+LCU unitary had a certified operator-norm error η\etaη, and its ideal accepted-branch norm were a=pKa=\sqrt{p_K}a=pK​​. For η<a\eta<aη<a, conservative bounds are

D(ρ~K,ρK)≤min⁡(1,2η/a),∣Δ⟨P⟩∣≤min⁡(2,4η/a),p~K≥(a−η)2.D(\widetilde\rho_K,\rho_K)\leq\min(1,2\eta/a),\qquad |\Delta\langle P\rangle|\leq\min(2,4\eta/a),\qquad \widetilde p_K\geq(a-\eta)^2.D(ρ​K​,ρK​)≤min(1,2η/a),∣Δ⟨P⟩∣≤min(2,4η/a),p​K​≥(a−η)2.
(5)

Reference discard/reset without conditioning cannot increase trace distance. This norm bound covers the coherent unitary; irreversible initialization, reset/readout faults and statistical noise have separate contracts. With a hypothetical η=10−4\eta=10^{-4}η=10−4, the reduced-state bound is about 0.0002922, Pauli-mean bias about 0.0005843, and acceptance lower bound about 0.4684533. The ledger separately computes a retry proposal from that lower bound. Certified synthesis is not implemented: a QDK mean-fit scalar is not such an operator-norm certificate.

Thermal polynomial error, coherent synthesis conditioning, sampling failure, acceptance failure and physical faults are separated. A proposed physical-failure allowance of 0.005 spans the capped complete attempts; no physical estimate or combined success guarantee is available. Physical routing, factories, reset/discard/readout timing, classical acceptance-processing wall time and fault-tolerant runtime remain unavailable. Classical aggregation/materialization time is recorded independently. The frozen Grover baseline is unchanged.

Run and scope¶

python scripts/generate_simulation_thermal_filter.py
pytest tests/test_simulation_thermal_filter.py

The reusable circuit module accepts at most four system qubits, 32 input Pauli terms, 256 aggregate terms and Taylor degree 12, with β∑j∣cj∣/2≤10\beta\sum_j|c_j|/2\leq10β∑j​∣cj​∣/2≤10 in the stated numeric domain. Circuit generation and dense validation are separate: ideal statevector checks stop at 12 total system/reference/label qubits. The artifact CLI uses a bounded one-qubit X/Z model, caps the validation grid at 64 cases and decomposed exports at 250,000 operations. A --no-sim generation explicitly marks checks, acceptance and workloads unavailable.

The notebook provides reusable saved labels. Static execution requires OPENQUANTUM_STATIC_BUILD=1; no widget objects or public kernel are needed. For standalone reproduction, put the source modules below beside the notebook and use the locked environment.

  • Thermal-filter source, explicit LCU access dependency, standalone generator

  • Coherent Bell+filter circuit, X measured trial, Z measured trial

  • Numerical results, logical/workload ledger, convergence CSV, MIT license

This is a checked small thermal-filtering component, not a scalable Gibbs algorithm or an equal-accuracy physical comparison. Scalable access, QSP thermal filtering, amplification and noncommuting measurement strategies at larger size remain planned.
