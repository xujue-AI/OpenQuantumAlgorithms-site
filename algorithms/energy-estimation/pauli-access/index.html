Energy estimation with Pauli product formulas

Motivation and intuition¶

An electronic Hamiltonian can be supplied as a list H=∑jcjPjH=\sum_jc_jP_jH=∑j​cj​Pj​ of Pauli words. Each word is easy to exponentiate using a basis change and parity computation. A product formula combines those elementary evolutions into approximate Hamiltonian access, which phase estimation then turns into an energy sample. Noncommutation introduces evolution error; finite clock width introduces a separate readout error Trotter, 1959Strang, 1968Childs et al., 2021.

This page is a variant of energy estimation. It uses the full four-spin-orbital H₂ fixture, whereas the main demonstration exploits an exactly implementable reduced dimer family. Its output is one approximate eigenenergy sample. Ground-state selection additionally requires preparation overlap and a valid repeated-readout procedure.

Fundamental algorithm and explicit access¶

The input is a real coefficient list with Qiskit labels ordered q[n-1] ... q[0]. Duplicate labels are combined with math.fsum; the resulting binary64 coefficients define the normalized input model. The analytic approximation bounds target that model and exclude incoming duplicate-aggregation roundoff.

For a Pauli word PPP, the generator implements e−ictPe^{-ictP}e−ictP by converting X with H and Y with S† then H, computing the parity of its nonidentity wires with CX, applying RZ(2ct)R_Z(2ct)RZ​(2ct), and undoing parity and basis changes. An identity term contributes a global phase. Its phase must be retained when access is controlled. No matrix exponential is appended as a quantum gate.

For δ=t/r\delta=t/rδ=t/r, first order applies every term exponential for δ\deltaδ in chronological list order. The symmetric version uses forward half-steps, a full final term and reversed half-steps. The circuit’s matrix multiplication order is the reverse of chronological gate order; its symmetric structure is unchanged.

Controlled access uses the same data basis/parity gates unconditionally, controls only the central RZ, then uncomputes. If the control is zero, the data operations cancel. A scalar identity applies a phase gate to the control. The selectable lift-all-gates implementation controls every elementary source gate instead; it is checked against the same ideal unitary and provides a compiler-cost comparison.

For LLL nonidentity terms of supports wjw_jwj​, one access has O(r∑jwj)O(r\sum_jw_j)O(r∑j​wj​) elementary operations. Static QPE uses m+nm+nm+n live wires and 2m−12^m-12m−1 complete controlled accesses, plus preparation, O(m2)O(m^2)O(m2) Fourier work and mmm phase readouts. These counts include Hamiltonian construction rather than assigning unit cost to an oracle.

Verified H₂ input and a small circuit¶

The fixed input is neutral H₂ at 0.735 Å, STO-3G, with a closed-shell RHF reference (spin=0) and four spin orbitals ordered as alpha then beta blocks. The pinned Qiskit Nature fixture supplies all 15 electronic Pauli coefficients Qiskit Nature contributors, 2024. Nuclear repulsion +0.7199689944489797 Ha is added separately. Hartree–Fock occupation [1,0,1,0] is |0101⟩, prepared with X on q0 and q2. The Nα=Nβ=1N_\alpha=N_\beta=1Nα​=Nβ​=1 particle sector has MS=0M_S=0MS​=0 and includes multiple total-spin sectors; it is not a singlet projection.

The inspected checkout is tag 0.7.2, released on February 23, 2024. The cached notebook execution dates to April 6, 2023 and records Qiskit Nature 0.6.0 and Python 3.9.16; its PySCF version is not recorded. All cited notebook cell indices are zero-based. We use its stored coefficients and do not rerun PySCF, integrals or fermion mapping. Their classical cost and molecular basis error are outside this supplied-Hamiltonian demonstration. The data source is Apache-2.0; the code and figures here are original MIT work.

The first circuit shows an actual YYYY term factor with basis/parity computation. The second shows the seven-wire QPE demo. Its controlled access boxes have explicit gate definitions and a complete primitive QASM export.

The default uses order 2, eight steps and three phase bits. It measures only the phase register. End-to-end resource analysis¶

The default termwise circuit has 12,027 primitives, including 6,953 CX, 3,043 RZ, 896 RX, 792 H, 169 S and 169 S†, two HF X gates and three phase measurements. Recorded dependency depth is 9,989. Every controlled access, term exponential, uncomputation and Fourier operation is included. Arbitrary rotations are not Clifford+T syntheses.

The logical record retains the full coefficients, parameters, source and QASM hashes, environment, measured construction/compilation times and exclusions. Its actual compiled scaling CSV varies n=2,4,6,8,12n=2,4,6,8,12n=2,4,6,8,12 and steps 1/4 for a synthetic local Pauli chain, with three phase bits. These rows are circuit-only examples. Their grid width changes with nnn; they are not a matched absolute-accuracy or molecular-growth comparison.

The surface-code report costs one full static trial, using the existing illustrative physical error 10-4, 100 ns gates and 500 ns measurements, a separate 0.005 modeled physical-fault allowance and 10-5 per-trial synthesis-model allowance. It returns three Pareto points. The fastest enumerated point projects 29,391 peak physical qubits and 398.174 ms; these are model values.

The lifted-control comparison uses the same H₂ input, eight steps, three phase bits and both allowances. Its circuit has 84,484 primitives and depth 59,007, with the same ideal output distribution but different compiler overhead. Its fastest enumerated model point uses 27,451 peak qubits and 708.288 ms. Lower logical gate count does not imply lower physical peak qubits. Both projections use the audited mean rotation-cost fit; neither supplies a concrete synthesis, accuracy or runtime-tail certificate. The frozen Grover baseline is unchanged.

Physical initialization/reset faults, external SCF/mapping and hardware-specific routing/decoder/classical readout latency remain excluded. A full ground-estimation workload needs a separately justified number of complete trials and preparation quality. Multiplying this one-shot cost by an arbitrary repetition count would not establish that contract.

Verification and formalization¶

The tests check X/Y basis conventions, active/inactive controls, identity phases, complete product formulas, actual QPE distributions and primitive lowering. Full four-qubit JW restriction to occupation indices [6,5,10,9] agrees with the reduced fixture. Both H and approximate U must preserve a selected particle sector before reference restriction. A regression rejects an accidentally invariant product unitary whose true H leaks from the proposed subspace.

Independent review checked Pauli/Strang commutator bounds, general Hermitian two-term cases, termwise controlled matrices and spectral-neighbourhood bounds. These are bounded numerical and mathematical checks. No reproduced Lean theorem or certified physical synthesis artifact covers this implementation.
