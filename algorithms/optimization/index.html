Optimization and variational methods

QAOA alternates an objective-dependent phase with a mixer, while VQE changes a trial state to reduce its energy Farhi et al., 2014Peruzzo et al., 2014. Both are hybrid workflows: classical parameter search and repeated state preparations needed to evaluate an objective belong to the algorithm. Here we make those operations inspectable on two small problems.

Implementation and evidence

The examples use explicit Qiskit circuits, exact statevector objectives, independent classical references, and separately seeded finite-shot experiments. The downloadable traces record every objective evaluation and all sampled readout. They check these particular circuits and runs; they establish no large-instance convergence guarantee or quantum advantage.

The resource record contains logical circuit inputs and the complete demonstrated workload. Arbitrary rotations remain unsynthesized. Physical qubits, surface-code runtime, fault budgets, and a physical Pareto frontier are planned, pending an audited synthesis and error-budget contract.

Finite-shot energy evaluation uses two groups. In the all-Z group, one bitstring yields the joint value −Z0−Z1-Z_0-Z_1−Z0​−Z1​; its sample variance includes covariance of the Z terms. In the all-X group, apply H to both qubits before computational-basis measurement and score 12X0X1\tfrac12X_0X_121​X0​X1​. Adding the group means estimates total energy. The measurement protocol requires a fresh ansatz preparation for each shot, and H basis changes and final measurements appear in the exports. The implementation obtains each group’s statevector probabilities and draws its counts classically. Shot noise can put a sampled energy below E0E_0E0​ even though the exact expectation obeys the variational bound.

A complete, deterministic parameter search¶

The original optimizer is a small coordinate polling routine. It evaluates the initial point, then every negative and positive coordinate displacement in a fixed order. If the best candidate reduces the minimized objective by more than 10-12, it accepts that candidate; otherwise it halves the step. The initial step is 0.4 radians. It stops when the step falls below 10-6 radians or after 128 sweeps, and records which condition stopped each run. Coordinates are wrapped modulo 2π2\pi2π.

QAOA initial points are (γ,β)=(0.2,0.1),(0.6,0.4),(−0.3,0.25)(\gamma,\beta)=(0.2,0.1),(0.6,0.4),(-0.3,0.25)(γ,β)=(0.2,0.1),(0.6,0.4),(−0.3,0.25). VQE initial angles are 0.6,−1.1,2.20.6,-1.1,2.20.6,−1.1,2.2. Every optimization objective uses an exact ideal statevector, with zero measurement shots. The run record retains accepted points, rejected candidates, iterations, evaluation counts, parameters, elapsed objective time, and total classical optimization time. Wall-clock timings include the classical simulator and are machine-dependent; they are not hardware execution times.

The primary fitted angles are then evaluated in separate ideal finite-shot experiments with seeds 7, 19, and 41, using 2,048 shots per measurement group per seed. Samples are drawn classically from statevector probabilities; repeated physical circuits are not executed. These experiments do not feed sampled objectives back to the optimizer. They report counts, sampled objectives, exact expectations, sample standard errors, and achieved output quality. Changing initialization probes optimization variability; changing the sampling seed probes readout variability. Neither experiment tests device noise, error mitigation, nor convergence of a sampled optimizer.

Logical workload and the pending physical handoff¶

The logical resource record accompanies actual measured OpenQASM 3 circuits. It records gate counts, depth, width, input preparation, all sampling repetitions, basis changes, and readout. The graph is a classical edge list and the Hamiltonian is three explicit Pauli terms; no data-loading oracle is assumed. Classical input parsing, physical reset and measurement time, and device routing are excluded. Reference calculations are included in the whole CPU workflow timer, but their separate time is unmeasured.

The demonstrated workload contains six exact classical optimization runs with their entire evaluation traces, plus three seeded readout experiments for each primary state. The ideal readout protocol represents 6,144 four-qubit QAOA preparations and 12,288 two-qubit VQE preparations, including both measurement bases. The generated ledger weights the explicit circuits by these shot counts; the samples themselves are drawn classically from statevector probabilities. Exact optimization evaluations use zero shots. Turning them into a hypothetical quantum optimization workload would require a stated per-evaluation measurement allocation and a new sampled optimization experiment. Multiplying one final circuit by an optimizer iteration count would not establish that workload’s convergence or accuracy.

The elementary exports retain H, CX, and one-qubit rotations. Arbitrary-angle RX, RY, and RZ gates are not synthesized into Clifford+T. The inputs support a later synthesis audit, but supply no validated T count, code distance, factory allocation, physical-qubit count, or quantum runtime. Coherent rotation approximation error and stochastic fault probability need separate budgets before a surface-code comparison. The existing Grover baseline remains a separate frozen example.

Generate, reproduce, and inspect¶

From a source checkout with the pinned Python 3.12 environment:

python scripts/generate_optimization.py
python -m pytest tests/test_optimization.py
python scripts/execute_notebooks.py

The notebook uses the same implementation as the artifact generator and provides the reusable outputs embedded above. Saved outputs serve a static website; no live Python kernel is required. To run the downloaded notebook separately, place the standalone module beside it and install the pinned environment.

The QAOA generator accepts a supplied graph and layer angles; the VQE generator exposes its ansatz parameter. Materialization is capped at 100,000 unitary gates before optional final measurements; the ledger includes those measurements. QAOA exact statevector simulation defaults to a small configured bound with a hard cap of 16 qubits; exhaustive enumeration has its own hard cap of 20. Circuit export is separate from these classical computations. Larger exports do not imply affordable simulation or project the number of optimization evaluations needed at larger sizes.
