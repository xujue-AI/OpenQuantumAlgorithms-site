A fixed 22-wire path-majority DQI pass

One complete fixed pass¶

Decoded quantum interferometry (DQI) combines signed clause-error contributions by preparing low-weight words, computing their syndromes, coherently clearing the error register and applying a Fourier transform Jordan et al., 2025. This page preserves one independently accepted 22-wire ideal primitive pass on a fixed two-path graph, recorded on 14 November 2026. Its full preparation and output probabilities were checked in the same forward pass. The saved records and all five original vectors are available below.

This ten-cycle has a linear classical optimum construction. The example makes preparation, coherent majority decoding and interference inspectable; it establishes no optimization advantage or generic useful-output guarantee.

Exact acceptance scope

Root acceptance covers one fixed Q22/N10/m10/n9 ideal primitive pass, explicitly known-zero initialization and unconditional readout probabilities. All 37 RY occurrences are unsynthesized. No actual shots were sampled and no reset-noise channel was modeled. Fault-tolerant costs, physical faults, hardware execution, general DQI guarantees and reproduced formal proof remain unavailable.

The curated acceptance record identifies the later parent record by its exact hash. Original source headers, ledger and diagnostic flags retain their earlier states: the raw diagnostics still say full_program_validated=false and parent_acceptance_recorded=false. This separate later acceptance does not rewrite them. The twelve-wire component and thirty-one-wire source retain their separate scopes; the 31-wire k=3 program remains generation only.

Original circuit and saved primitive stream¶

This original schematic groups long stages for readability. The actual QASM, actual NDJSON and unchanged ledger preserve every emitted primitive, reset, barrier and readout mapping.

Preparation is counter-controlled and reverses its increments. Three Z gates on clause wires 0, 1 and 5 encode the fixed signs. Eighteen CX gates explicitly compute incidence syndromes, so access to the graph/sign data is part of the circuit. Each five-edge path is recovered by computing four prefix parities and their majority flag, XORing the decoded word into the clause targets, then reversing the flag and prefix computation. Two 525-primitive decoders reuse clean scratch; their 68 full phase-exact CCX blocks are lowered into H/CX/T/T-dagger gates in the complete stream. No opaque decoder oracle is charged as a free operation.

Five original full vectors and byte authentication¶

The dedicated vector ZIP keeps all five original files together: initial state, preparation reference, preparation actual, final reference and final actual. Each holds 4,194,304 little-endian complex128 amplitudes as interleaved float64 real/imaginary values, with wire zero least significant. Each raw member is 67,108,864 bytes; the complete uncompressed payload is 335,544,320 bytes. Streaming compression preserves every byte and each separately recorded SHA-256.

The manifest binds all public scientific/source bytes and the five member hashes. The stdlib saved checker authenticates an externally pinned manifest, every file and all five ZIP members in bounded streams. It replays no circuit, extracts no vector and decodes no values. The packet README explains inspection and the absent private execution inputs. The exact profile, independent verifier and driver are immutable source snapshots, not a new execution grant or runnable public environment.

Accounting, theory boundaries and credits¶

Preparation, sign/incidence access, coherent decoding, scratch erasure and readout all belong to the recorded complete draw. Only one ideal pass was executed. A future repetition plan would repeat these operations and add assignment receipt, edge scoring and best-score selection; no actual shots or matched quality/repetition resource comparison is supplied here.

The whole scientific process completed in 43.711875165987294 seconds, including startup, output writes, EOF, reap and cleanup. Maximum sampled RSS was 210,960,384 bytes; external sampled CPU was 41.71202464 seconds. These are observations of one local CPU process, not portable benchmark promises or unsampled-peak measurements. The declared 212,342,784-byte numerical-buffer envelope includes reserve and is separate from RSS; it is not a runtime internal-allocation proof. No fault-tolerant cost estimate is attached: rotation synthesis, synthesis error allocation, scheduling, factories, code distance and physical faults remain excluded. The existing surface-code baseline is unchanged.

Successful decoding on the prepared weight-two domain does not establish the stronger every-neighbor premise, OPI access assumptions or generic quality guarantees in the cited cycle-code/OPI results Apte et al., 2026Rosmanis, 2026. Larger full passes, decoder co-design and matched resource comparisons remain planned. This fixed check supplies neither a hard-family advantage nor a local formal theorem.

The implementation and figure are original project work under MIT. The accepted job used CPython 3.12.14, NumPy 2.5.4 (recorded git a3d0ef1df045b858e68115001fdabc930bb3b68c) for local CPU primitive kernels and psutil 7.2.2 for private monitoring. No quantum SDK, resource estimator or new notebook ran for this increment. Exact source pins, package roles and complete license notices appear in the credits and curated environment record.
