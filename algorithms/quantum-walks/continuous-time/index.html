Continuous-time walks on the hypercube

Motivation and intuition¶

A continuous-time walk spreads amplitudes by evolving under a graph’s adjacency Hamiltonian. On the nnn-dimensional hypercube, a vertex is an nnn-bit string and each edge flips one bit. The adjacency therefore has a particularly simple representation: a sum of Pauli X operators. The terms commute, so every coordinate evolves independently. This supplies a transparent companion to the coined cycle walk, whose coin and conditional shifts generate different interference.

Hypercube walks and their mixing behavior are studied by Moore and Russell Moore & Russell, 2002. Our explicit convention below fixes the edge weight and time units. This special factorization is also easy to simulate classically; it establishes no quantum advantage or generic graph-access implementation.

The classical input is the register width nnn, coupling JJJ, time ttt, and starting vertex xxx. Prepare ∣x⟩|x\rangle∣x⟩ with one X gate per set bit.

Here JJJ specifies the energy scale and ttt is in inverse-energy units with ℏ=1\hbar=1ℏ=1. This model-evolution time is separate from the physical duration of the compiled gate circuit. Since distinct-coordinate Pauli terms commute,

U(t)=⨂q=0n−1(cos⁡(Jt)I−isin⁡(Jt)X)=∏q=0n−1RX(2Jt).U(t)=\bigotimes_{q=0}^{n-1}\left(\cos(Jt)I-i\sin(Jt)X\right) =\prod_{q=0}^{n-1}R_X(2Jt).U(t)=q=0⨂n−1​(cos(Jt)I−isin(Jt)X)=q=0∏n−1​RX​(2Jt).

The circuit constructs these actual rotations. It does not append a dense matrix exponential or load graph eigenvectors. Basis state preparation is explicit; arbitrary amplitude loading is outside this example.

For a destination yyy, let h=popcount⁡(xxory)h=\operatorname{popcount}(x\mathbin{\mathrm{xor}}y)h=popcount(xxory). The analytic probability is

P(y,t)=sin⁡2h(Jt)cos⁡2(n−h)(Jt),P(x,t)=cos⁡2n(Jt).P(y,t)=\sin^{2h}(Jt)\cos^{2(n-h)}(Jt),\qquad P(x,t)=\cos^{2n}(Jt).P(y,t)=sin2h(Jt)cos2(n−h)(Jt),P(x,t)=cos2n(Jt).
(3)

At ∣Jt∣=π/4|Jt|=\pi/4∣Jt∣=π/4, all 2n2^n2n vertices have probability 2−n2^{-n}2−n. At Jt=π/2Jt=\pi/2Jt=π/2, the walk reaches the bitwise antipode with amplitude (−i)n(-i)^n(−i)n. Global phases matter for a coherently controlled evolution: at Jt=πJt=\piJt=π, U=(−1)nIU=(-1)^nIU=(−1)nI, not always III.

The graph’s degree is nnn. Choosing normalized adjacency means J=1/nJ=1/nJ=1/n, so the uniform-time value becomes t=πn/4t=\pi n/4t=πn/4. Choosing J=1J=1J=1 instead gives t=π/4t=\pi/4t=π/4. Times from differently normalized models must not be compared directly.

End-to-end resource analysis¶

For one trial, logical space is nnn qubits. Input preparation uses popcount⁡(x)\operatorname{popcount}(x)popcount(x) X gates, evolution uses nnn RX gates for nonzero represented JtJtJt, and complete position readout uses nnn measurements. The coordinate rotations can form one logical layer; factory throughput and error-correction scheduling still determine physical time. The ability to use nnn rotations for arbitrary represented time is a consequence of this commuting Hamiltonian, not a fast-forwarding method for arbitrary graphs.

Our resource task is one fixed return-probability mean, obtained from the indicator [y=x]∈[0,1][y=x]\in[0,1][y=x]∈[0,1]. It is different from reconstructing a uniformly accurate histogram over all 2n2^n2n vertices. Independent Bernoulli shots obey

M≥⌈log⁡(2/δS)2ϵS2⌉.M\ge\left\lceil\frac{\log(2/\delta_S)}{2\epsilon_S^2}\right\rceil.M≥⌈2ϵS2​log(2/δS​)​⌉.
(4)

For ϵS=.03\epsilon_S=.03ϵS​=.03 and δS=.005\delta_S=.005δS​=.005, this requires 3,329 complete trials. The canonical generator passes a separate 10-4 allowance for synthesis bias, giving an absolute-error target .0301. A separate .005 physical-fault allowance spans all trials; it is not added to the coherent bias as an independent random fault. The helper’s configurable default synthesis allowance is .01; that different default is not the published canonical setting.

The ledger must multiply preparation, rotations and every position measurement by MMM. Classical decoding compares each nnn-bit output with xxx; its time and communication latency are unmeasured. The clean zero input is assumed, with initialization timing/faults excluded. The parent chapter’s conditional surface-code reports specify code distances, factories, hardware error rates and complete serial workloads. A raw RX count or constant logical depth does not determine physical qubits or runtime.

QDK’s arbitrary-rotation cost is an empirical mean-fit model. It does not supply a concrete Clifford+T approximation or certified output-error bound. The synthesis-bias allocation is therefore conditional on the model scalar bounding output-distribution variation. No certified overall output-confidence statement follows from that assumption. The frozen Grover baseline supplies reporting conventions and hardware profiles, not physical counts for this walk.

Verification and formalization¶

Checks retain complex amplitudes, global phases, nonzero starting vertices, negative couplings/times, normalized versus unnormalized time conventions, final measurement maps, and lowering equivalence. Uniformity, antipodal transfer, periodicity and dense adjacency structure have independent references. A deliberately disagreeing reference is rejected by the checker. Results must meet a declared 10-12 numerical tolerance before they are labeled checked.

No Lean formalization is integrated for this implementation. The factorization above is a mathematical explanation; a proof artifact would need a reproduced toolchain, theorem assumptions and an explicit circuit connection. General continuous-time graph walks additionally require implemented graph access and approximation analysis; they are not supplied by this hypercube circuit.

The implementation uses original MIT code with Qiskit 2.6.2 (Apache-2.0 license), NumPy and SciPy. Exact build versions, source hashes and circuit digests accompany the generated artifacts.

Optional background video: MIT Lecture 12: Quantum Dynamics explains unitary time evolution. It supports the Hamiltonian viewpoint rather than validating this walk implementation or its resource estimate.
