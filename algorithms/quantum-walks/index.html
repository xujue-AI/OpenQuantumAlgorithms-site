Quantum walks

Motivation and intuition¶

A classical random walk adds probabilities along possible routes. A quantum walk propagates amplitudes, so routes can reinforce or cancel when they meet. A coin supplies the direction register for a discrete walk; continuous-time walks instead evolve under a graph Hamiltonian. Quantum walks are useful primitives in search, sampling and quantum simulation, but their graph access, preparation and output requirements determine an application’s cost Aharonov et al., 2001.

This chapter implements a Hadamard-coin walk on a cycle. Separate method pages implement SKW-style marked-hypercube search with an actual equality oracle and continuous-time hypercube dynamics. Their graphs, evolution and output contracts differ; the resource plots are not an equal-task advantage comparison.

Implemented scope

Binary carry gates implement the coin-controlled cycle shifts. Small circuits are checked against independent permutation matrices and amplitude recurrences. Complete measured circuits, source code, size sweeps and conditional surface-code reports are supplied. No dense shift/evolution matrix constructs a quantum gate. The bounded SKW search separately checks its joint marked-state reflection, clean workspace and literal Clifford+T sequence. General graph access, other marked-search families, Szegedy walks, certified arbitrary-rotation synthesis and an integrated Lean proof remain further implementations.

Fundamental algorithm and task contract¶

Encode N=2nN=2^nN=2n positions in nnn bits and use one coin qubit. A step is

U=S(Hc⊗I),S∣c,x⟩=∣c,x+(2c−1) mod N⟩.U=S(H_c\otimes I),\qquad S|c,x\rangle=|c,x+(2c-1)\bmod N\rangle.U=S(Hc​⊗I),S∣c,x⟩=∣c,x+(2c−1)modN⟩.
(1)

Chronologically apply the Hadamard to the coin, then shift. Coin zero moves left; coin one moves right. The coin occupies wire q[n], and q[0] is the least significant position bit. The n=1n=1n=1 case has coincident left/right neighbors and is a degenerate two-vertex example; the main sweep starts at n=2n=2n=2.

The displayed input is position zero and coin (∣0⟩+i∣1⟩)/2(|0\rangle+i|1\rangle)/\sqrt2(∣0⟩+i∣1⟩)/2​, prepared by H then S. Other implemented inputs are basis positions and coin zero or one. The output contract is one return-event probability after a stated number of steps. Every complete trial measures all position and coin wires. Classical decoding ignores every coin outcome and checks whether the position equals its start; it never postselects a coin value. A full histogram is a bounded illustration, not the same precision contract.

For a conditional increment, visit the position bits from high to low: flip bit jjj when the coin and all lower bits are one, then flip bit zero under the coin. This implements binary carry without scratch wires. Reversing that sequence implements decrement. Sandwich the decrement with coin X gates to control it on zero. Both coin branches are coherent and their relative phase is retained.

Important variants¶

The continuous-time hypercube walk uses H=J∑jXjH=J\sum_jX_jH=J∑j​Xj​ and e−iHt=∏jRX(2Jt)e^{-iHt}=\prod_jR_X(2Jt)e−iHt=∏j​RX​(2Jt). This special graph factorizes into independent qubit rotations and is easy to simulate classically. It is not an implementation of arbitrary graph Hamiltonians.

The implemented SKW-style search uses a supplied equality mark, a binary direction coin and an explicit hypercube shift. Its default 11-wire circuit has an independent small reference and separate fixed-workload surface-code report. General graph search, multiple/application predicates and Szegedy transition-state preparation remain planned; their complexity is not inferred from either bounded walk.

End-to-end resource analysis¶

Size, time and output scaling¶

The logical scaling data contains 12 actual compiled circuits: n=2,3,4,5,6,8n=2,3,4,5,6,8n=2,3,4,5,6,8 for the cycle at four steps and the hypercube at Jt=0.7Jt=0.7Jt=0.7. Every row includes basis/coin preparation, all primitive controlled shifts or rotations, final readouts and the declared number of trials. Statevector/recurrence checks are run for the cycle rows; bounded dense adjacency and analytic checks are run for the hypercube rows. These are different graph families with 2n2^n2n vertices.

For one fixed return indicator in [0,1][0,1][0,1], Hoeffding gives

M≥⌈ln⁡(2/δS)2ϵS2⌉=3329,ϵS=0.03,δS=0.005.M\ge\left\lceil\frac{\ln(2/\delta_S)}{2\epsilon_S^2}\right\rceil =3329,\qquad\epsilon_S=0.03,\quad\delta_S=0.005.M≥⌈2ϵS2​ln(2/δS​)​⌉=3329,ϵS​=0.03,δS​=0.005.
(2)

The same absolute sampling tolerance is used at every size; it is not a relative-error target for rare return events. The coherent synthesis-model allowance is separately 10-4 per output, with ideal algorithmic bias zero for the specified walk circuit. The total conditional observable allowance is 0.0301. A separate physical-fault allowance 0.005 spans all 3,329 trials. The logical reports retain per-trial and shot-weighted gate/readout counts. Seeded NumPy draws from the validated ideal marginal are classical simulations, not hardware executions.

Our full statevector and recurrence store O(2n+1)O(2^{n+1})O(2n+1) amplitudes; the dense reference stores O(4n+1)O(4^{n+1})O(4n+1) matrix entries. Those are limits of the implemented checkers, not lower bounds on all classical simulation methods. At small step count a sparse reachable-position simulation can be much smaller, and the hypercube has a product formula. No classical-hardness or speedup claim follows from the circuit width.

The reports retain code distances, factory choices, source/QASM digests, serial runtime and physical-fault model scores. Peak qubits are reused across serial trials. Peak times runtime is a rectangular space-time proxy, not an occupancy integral. The coined and continuous-time primitive QASM exports describe complete measured trials. The pinned exporter may omit an overall compiled global phase; these exports are not phase-preserving specifications for later coherent control.

QDK’s arbitrary-rotation cost is a mean fit for random angles, not a concrete Clifford+T sequence, approximation certificate or runtime-tail guarantee. Conditional confidence assumes its scalar bounds output-distribution variation; certified confidence remains unavailable. Physical initialization/reset timing and faults, processor routing and classical readout/control/communication latency are excluded. QDK abstracts Clifford scheduling, so the original circuit’s dependency depth is not a measured hardware schedule. These exclusions prevent calling the result a fully certified hardware implementation.

Separate marked-search workload¶

Marked-hypercube search counts the complete supplied oracle, five clean work wires, coin/shift, literal 392-T/T† lowering and every measured trial for its prescribed four-step instance. Its surface-code rows cost 12,288 ideal frequency-estimate preparations, separately from the ten-trial ideal at-least-one search task. These saved results have their own output and failure budget; they do not extend the unmarked cycle scaling table or establish a cross-method advantage.

Verification and formalization¶

The shift is compared directly with an independently built permutation on both coin branches and random coherent inputs. The complete walk is compared with an independently constructed S(H⊗I)S(H\otimes I)S(H⊗I) matrix and a matrix-free amplitude recurrence. Tests cover carries/wraparound, bit order, relative phases, all input coins, parity, decomposition, all final measurements, invalid parameters and separate generation/simulation limits. Continuous-time tests use an independent bit-flip adjacency exponential and Hamming-distance product probabilities.

No Lean proof is integrated. A linked formal library would need a reproduced theorem, its input/register assumptions and a connection to these source circuits and their lowering. The available checks are bounded numerical/functional evidence.

Reproduce and generate larger circuits¶

Use Python 3.12 and the locked environment with the public code package:

python scripts/generate_quantum_walks.py --estimate
pytest tests/test_quantum_walks.py tests/test_quantum_walks_continuous.py
python scripts/generate_quantum_walks.py --qubits 10 --steps 2 \
  --no-sim --no-scaling --output-dir artifacts/walk-10

The cycle generator allows at most 12 position bits and 256 steps, subject to a conservative controlled-shift work guard and a 250,000-operation compiled-export cap. Temporary transpilation cost is not certified by the source guard. Actual statevector/recurrence checks stop at 12 total wires and 64 steps; dense cycle matrices stop at six position bits. The continuous-time module has its own limits. Larger exports explicitly report simulation as unperformed.

The notebook includes optional live bounded controls. Static pages reuse its saved circuit/result outputs; controls need a local or Binder Python kernel, not a maintained website backend.
