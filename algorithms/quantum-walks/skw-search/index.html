Marked-hypercube search

Motivation and intuition¶

A marked vertex changes the coin used by a quantum walk. Repeated coin and shift operations make paths interfere, increasing the chance of reading that vertex at suitable times. Shenvi, Kempe and Whaley introduced a hypercube search algorithm with O(N)O(\sqrt N)O(N​) oracle calls in its stated search model Shenvi et al., 2003. This page implements a bounded teaching instance with a fully constructed predicate, rather than treating the marking operation as a free box.

Implemented scope

The default four-dimensional hypercube circuit and its independent classical reference are executed. The supplied marked value is known to the constructor: it specifies an equality predicate, not an unknown database or application benchmark. Larger supported circuits have separate source-only exports. The physical report is a conditional estimate of one fixed readout workload, and there is no integrated Lean proof or hardware execution.

Fundamental algorithm and task contract¶

For hypercube dimension ddd, positions are x∈{0,…,2d−1}x\in\{0,\ldots,2^d-1\}x∈{0,…,2d−1} and the coin selects one of ddd directions. This implementation uses d=2rd=2^rd=2r, with rrr coin qubits, ddd position qubits and d+r−1d+r-1d+r−1 clean work qubits. Coin bits occupy the low wires, so a basis index is

j=c+2rx+2d+rw.j=c+2^r x+2^{d+r}w.j=c+2rx+2d+rw.
(1)

The work register begins at zero. Hadamards on all d+rd+rd+r active wires prepare uniform coin and position. With ∣s⟩=d−1/2∑c∣c⟩|s\rangle=d^{-1/2}\sum_c|c\rangle∣s⟩=d−1/2∑c​∣c⟩, one implemented iteration is

Uimpl=SG~R,R=I−2∣s,m⟩⟨s,m∣,G~=I−2∣s⟩⟨s∣,U_{\rm impl}=S\widetilde G R,\qquad R=I-2|s,m\rangle\langle s,m|,\qquad \widetilde G=I-2|s\rangle\langle s|,Uimpl​=SGR,R=I−2∣s,m⟩⟨s,m∣,G=I−2∣s⟩⟨s∣,
(2)
S∣c,x⟩=∣c,x⊕2c⟩.S|c,x\rangle=|c,x\oplus2^c\rangle.S∣c,x⟩=∣c,x⊕2c⟩.
(3)

The chronological order is marking, coin, shift. The joint reflection uses coin Hadamards and X wrappers to convert the supplied target condition into an all-one phase. A clean CCX chain computes the conjunction, Z marks its last flag and reversed CCX gates uncompute every flag. The coin uses the same reflection construction on its own register. Each shift explicitly matches a binary coin label and flips the corresponding position bit.

The usual SKW coin is G=2∣s⟩⟨s∣−IG=2|s\rangle\langle s|-IG=2∣s⟩⟨s∣−I, with a −I-I−I coin block at the marked position. Consequently this circuit’s iteration differs from that standard step by an overall minus sign. The (−1)k(-1)^k(−1)k phase leaves uncontrolled search probabilities unchanged; phase-correct coherently controlled reuse is outside the exported circuit contract.

A complete trial measures every coin, position and work wire. Decode the position bits and compare with the supplied mark. Coin outcomes are summed, and work outcomes are retained. Clean-work leakage is a circuit check, not a postselection rule. The oracle’s intended semantics require initially clean work, rather than an arbitrary work-register input.

Important variants and scope¶

This implementation covers a single supplied equality mark on a binary-coin hypercube. The unmarked coined-cycle walk and continuous-time hypercube walk use different graph, coin/evolution and output contracts. Multiple marks, general graph access, Szegedy transition-state preparation, application predicates and a larger success-scheduled search study remain planned. The original paper’s query bound is external theory, not a scaling result measured by this four-step example.

End-to-end resource analysis¶

Source size and bounded scaling¶

Total logical width is Q=2(d+log⁡2d)−1Q=2(d+\log_2d)-1Q=2(d+log2​d)−1. For kkk iterations the source circuit has O(kdlog⁡d)O(kd\log d)O(kdlogd) gates, plus d+log⁡2dd+\log_2dd+log2​d preparation Hadamards and QQQ final measurements. Writing r=log⁡2dr=\log_2dr=log2​d, each joint mark has 2(d+r−1)2(d+r-1)2(d+r−1) CCX gates. The shift has ddd CX for r=1r=1r=1, or d(2r−3)d(2r-3)d(2r−3) CCX for r≥2r\ge2r≥2. The coin has one Z for r=1r=1r=1, one CZ for r=2r=2r=2, or 2(r−1)2(r-1)2(r−1) CCX for r≥3r\ge3r≥3. All H/X wrappers and uncomputation are included in the actual export counts.

The main four-step source has 56 CCX: 40 in marking and 16 in shifts. Deterministic optimization-level-zero Qiskit lowering yields 392 T/T†, 340 CX and no arbitrary-angle rotations. Its standard CCX sequence has seven T/T† gates, so approximate rotation synthesis is unnecessary for this literal logical circuit. This does not remove physical fault or factory costs.

Conditional model and exclusions

The complete logical circuit and ledger retain preparation, the explicit oracle, work cleanup, coin/shift and readout. The table costs their QDK/PSSPC count abstraction with modeled code distance, factories and reliability; individual original H/CX operations are not separately charged or routed. Physical initialization/reset, routing, communication/feedback, classical input/compilation/scoring time and hardware reliability certificates are excluded or unmeasured. Logical zero-input initialization is assumed. The factory and code models do not certify hardware success. Peak qubits times serial runtime is a reported resource product, not a measured active-qubit integral. No physical size sweep, matched advantage claim or new factory search is supplied here. The frozen Grover baseline remains unchanged.

The report retains every Pareto point and the selection CSV. Its original producer/adapter hashes and historical source revision are preserved; the tables are saved evidence rather than newly regenerated estimates.

Classical simulation, verification and formalization¶

The saved oracle check evaluates all 64 clean-work active basis inputs against an independently formed rank-one reflection. Tests independently build the standard SKW coin blocks and shift, check coherent phases and work cleanup, verify the local seven-T CCX operator, compare the selected full 11-wire prepared state after lowering, retain every measurement outcome and reject unsupported sizes. The physical preprocessing does not check the full 2048×20482048\times20482048×2048 walk operator. Numerical tests are bounded evidence, rather than a theorem for all inputs.

A full statevector stores 2Q2^Q2Q complex amplitudes; a dense active-space matrix stores 4d+r4^{d+r}4d+r entries. Those references are intentionally limited. No Lean or Rocq proof is integrated for this walk. The separate finite classical C4 optimization proof does not prove its oracle, coin, shift, success or physical resources.
