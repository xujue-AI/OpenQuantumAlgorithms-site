Quantum linear systems: gates, normalized output and complete attempts

This original notebook implements HHL on a dyadic commuting matrix and a spectrum-matched QSVT inverse. Both prepare a normalized solution state and estimate Z(q0)Z(q_0)Z(q0​); neither returns every entry of the classical vector. Dense solves below are independent bounded references, never quantum gates. Qiskit2.6.2 is Apache2.0; NumPy2.5.4/SciPy1.18.1 are BSD3Clause; our source is MIT. The chapter cites HHL and QSVT primary papers.

Actual HHL access, phase register and reciprocal rotation¶

A=14I+14(I−X)/2A=\tfrac14 I+\tfrac14(I-X)/2A=41​I+41​(I−X)/2, eigenvalues1/4,1/2. Controlled evolution contains the identity-component control phase and controlled RX gates. The two clock bits represent the eigenvalues exactly; the success flag rotation multiplies amplitudes by (1/4)/λ(1/4)/\lambda(1/4)/λ. The inverse QPE erases the clock. Every attempt measures all wires at the end.

Modern QSVT: an implemented spectrum-matched variant¶

The normalized matrix is B=A/(1/2)=.75I−.25XB=A/(1/2)=.75I-.25XB=A/(1/2)=.75I−.25X. Three explicit Pauli block encodings and four projector phases implement p(B)p(B)p(B) with p(x)=(5x−4x3)/4p(x)=(5x-4x^3)/4p(x)=(5x−4x3)/4. At the specified eigenvalues1/2,1, p(x)=1/(4x)p(x)=1/(4x)p(x)=1/(4x), so the accepted state is the same solution. Away from these eigenvalues this cubic is not a general high-accuracy inverse.

Complete measured attempts and fresh-trial repetitions¶

We include the input gates, every access and uncomputation, actual output basis changes, and final data/ancilla measurements. Rejecting an ancilla result does not remove its cost. The following counts precede Clifford+T synthesis. The capped workload is an unexecuted ideal proposal, with independent .005 statistical and .005 no-acceptance allowances. It is not a hardware confidence certificate.

rows=[]
for name,c,p in [('HHL',hhl.measured_hhl_trial(system),result['success_probability']),('QSVT',qsvt.qsvt_measured_trial(),qresult['acceptance_probability'])]:
    compiled=hhl.decompose(c)
    workload=hhl.accepted_observable_workload(p)
    rows.append({'method':name,'logical qubits':compiled.num_qubits,'CX':compiled.count_ops().get('cx',0),'rotations':sum(compiled.count_ops().get(g,0) for g in ('rx','ry','rz')),'measurements':compiled.count_ops()['measure'],'accepted samples':workload['accepted_samples'],'attempts per slot':workload['attempt_cap_per_accepted_slot'],'capped attempts':workload['total_capped_attempts']})
display(pd.DataFrame(rows))
