Saved evidence for a finite full-XX reusable-bath prototype

The one-spin component run completed 165 selected tests, two source exports, 17 compact circuit checks and 81 distinct ODE solves. Its overall validation stopped during the original notebook-display stage. A later corrected saved-only replay completed all five code cells locally without errors. These are separate results: component evidence and a read-and-display replay.

This notebook authenticates and displays the same saved data. Its code cells do not repeat quantum evolution, ODE solves, tests, source generation, sampling, synthesis or resource estimation. The code cells match the locally replayed version; the explanatory Markdown has been clarified afterwards. The original executed receipt and failed-run history are preserved separately.

The records retain all_components_verified=false. The requested 0.05 absolute system-Z error is not certified; exact continuum and physical budgets remain unavailable. Full-state and Choi arrays are finite-channel diagnostics; the original negative endpoints and nonzero target residuals remain visible.

Open the saved evidence in Jupyter¶

Download this notebook and the reusable-bath evidence bundle. Unzip the bundle beside the notebook; it creates reusable-bath-evidence/ with the manifest and its 18 saved files (20,586,435 bytes in total).

Open the notebook in the project’s locked Python 3.12 Jupyter environment, choose the ordinary Python 3 (ipykernel) kernel and select Run All. The loader also locates the repository copy from notebooks/ or the project root. No private environment variable, execution record or custom kernel is required. Run All verifies saved-file hashes and displays JSON, figures and QASM metadata; it does not execute the source snapshots in the bundle.

def read_regular_saved_file(name, expected_bytes):
    relative = PurePosixPath(name)
    if (relative.is_absolute() or '..' in relative.parts
            or relative.as_posix() != name):
        raise ValueError('Nonportable saved filename')
    current = artifact_root
    for part in relative.parts[:-1]:
        current = current / part
        if not stat.S_ISDIR(current.lstat().st_mode):
            raise ValueError('Saved artifact directory is nonregular or symlinked')
    target = artifact_root / relative
    info = target.lstat()
    if not stat.S_ISREG(info.st_mode) or info.st_size != expected_bytes:
        raise ValueError('Saved artifact is nonregular or has the wrong length')
    data = target.read_bytes()
    if len(data) != expected_bytes:
        raise ValueError('Saved artifact length changed while reading')
    return data

# Reject extra files, directories and symlinks in the curated evidence directory.
actual_files = set()
for child in artifact_root.iterdir():
    mode = child.lstat().st_mode
    if stat.S_ISREG(mode):
        actual_files.add(child.name)
    elif child.name == 'source' and stat.S_ISDIR(mode):
        for entry in child.iterdir():
            if not stat.S_ISREG(entry.lstat().st_mode):
                raise ValueError('Source snapshot contains a nonregular file')
            actual_files.add('source/' + entry.name)
    else:
        raise ValueError('Unexpected saved artifact directory or nonregular file')
if (actual_files != EXPECTED_FILES | {'artifact-manifest.json'}
        or len(actual_files) != EXPECTED_FILE_COUNT):
    raise ValueError('Saved-file allowlist does not match the exact 19-file bundle')

manifest_bytes = read_regular_saved_file('artifact-manifest.json', EXPECTED_MANIFEST_BYTES)
if sha256(manifest_bytes).hexdigest() != EXPECTED_MANIFEST_SHA256:
    raise ValueError('Saved manifest hash mismatch')
manifest = json.loads(manifest_bytes)
if (manifest.get('schema_version') != 1
        or manifest.get('kind') != 'portable_saved_reusable_bath_evidence'
        or manifest.get('all_components_verified') is not False):
    raise ValueError('Unexpected saved manifest scope')
records = manifest.get('files')
if not isinstance(records, dict) or set(records) != EXPECTED_FILES:
    raise ValueError('Manifest payload allowlist mismatch')

saved_files = {}
total_bytes = len(manifest_bytes)
for name in sorted(EXPECTED_FILES):
    record = records[name]
    if (not isinstance(record, dict) or set(record) != {'bytes', 'sha256'}
            or type(record['bytes']) is not int or record['bytes'] < 0):
        raise ValueError('Malformed saved file record')
    total_bytes += record['bytes']
    if total_bytes > EXPECTED_TOTAL_BYTES:
        raise ValueError('Saved bundle exceeds its exact byte bound')
    data = read_regular_saved_file(name, record['bytes'])
    if sha256(data).hexdigest() != record['sha256']:
        raise ValueError('Saved artifact hash mismatch: ' + name)
    saved_files[name] = data
if total_bytes != EXPECTED_TOTAL_BYTES:
    raise ValueError('Saved bundle total byte length mismatch')

def saved_json(name):
    return json.loads(saved_files[name])

Forward schedule and channel contract¶

The original one-spin Hamiltonian is (H_\omega(t)=Z_S/2-\omega Z_E/2+.08 f(t)X_SX_E), with (f(t)=\exp[-(t-8)^2/8]) on ([0,16]). Both XX parity branches remain. The main request uses all 17 Gauss–Legendre frequencies on [0,2], 192 fresh-draw rounds and 256 positive-time midpoint steps per round. The bath is prepared by an explicit classical bit/X and discarded/reset after each round.

The system starts in excited computational |0>; its ground is |1>. Thermal mode has beta=1 and bath probability 1/(1+exp(omega)); ground mode uses bath |0>. Fresh choices give the power of the averaged channel, not an average of fixed-frequency channel powers. A trajectory is not a purification.

Finite channel, Gibbs and ground evidence¶

T17 is the midpoint GL17 channel. Q17_hat and C65_hat are full-Hamiltonian ODE proxies at 17 and 65 nodes. Same-midpoint source/SDK agreement checks an implementation component; source/ODE disagreement is a separate Trotter proxy diagnostic. Four physical inputs span the full reduced map.

The saved endpoint records include full reduced states, Gibbs/ground target residuals, ground/excited populations, fixed points and 192-round mixing. Channel and output states are never renormalized. Raw Choi/trace/CP/TP checks use those unmodified values; only the independent Gibbs target is normalized. None of the finite proxy comparisons certifies the exact continuous-frequency channel or the complete .05 ledger. The run status and individual negative/error fields remain visible.

Workload and remaining accounting¶

The full source ledger charges every forward primitive, optional bath X, reset and final readout. Compact Operator circuits contain only evolution; state probes are cached matrix inputs. Scalar K/L/M/P counting is a separate interface and does not generate coefficients, circuits or reference jobs. One-spin round/time/frequency scaling is not a completed large-n generator.

The 29,958 complete readout preparations per mode (59,916 total) remain an unexecuted statistical projection. Coherent error is a complete-preparation bias; it is not multiplied by this population. Synthesis, T/depth/routing, physical reset/feedback/noise, idle/controller cost, factories, physical qubits/runtime and total physical fault success remain uncomputed.

Source and reproducibility¶

The implementation and diagrams are original. The scientific-only protocol, one-spin source, inspection-only numerical source and exact environment lock are saved in the bundle. This notebook checks their bytes without importing or executing them. The source recipe hash is only a provenance identifier.

For normal source use, work inside the extracted source/ directory and pass Path("reusable_bath_protocol.json") explicitly to load_protocol; this uses the bundled scientific protocol and avoids the repository fallback. count_source, iter_round_operations, iter_operations, operation_qasm and QASM_HEADER are standard-library interfaces for counts and bounded primitive operations. The count CLI is python reusable_bath.py --count 192 256 17 --mode ground. Counting is not a quantum simulation or a general large-system generator. The preserved write_qasm function needs a managed budget; the numerical reference needs a bounded caller. They are restricted inspection interfaces, and no private validation controller or runner is supplied.

Saved execution used Python 3.12.14, NumPy 2.5.4 (BSD-3-Clause), SciPy 1.18.1 (BSD-3-Clause), Qiskit 2.6.2 (Apache-2.0), IPython 9.18.1 and ipykernel 7.4.0. Replay uses standard-library file, hash and JSON operations plus IPython JSON, SVG and PNG display in the ordinary locked Jupyter environment.

The motivating method is Ding, Zhan, Preskill and Lin, Simple and efficient end-to-end quantum thermal and ground state preparation, Nature Physics 22, 1679–1683 (2026), DOI 10.1038/s41567-026-03389-y, arXiv:2508.05703v3. The finite one-spin example does not reproduce the general theorem. Efficient quantum thermal simulation, DOI 10.1038/s41586-025-09583-x, is a distinct filtered-jump/coherent-correction/access construction.

The successful local display replay does not turn the original full-run failure into a success, certify the requested total error, or supply a continuum or physical certificate. all_components_verified remains false.
