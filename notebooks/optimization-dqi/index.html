Decoded quantum interferometry: portable saved-component verification

This notebook uses the supplied standard-library verifier to check the portable saved default component. Run it with the supplied Python 3.12 requirements lock. A downloaded notebook can sit beside the bundle files; in the repository, the cells locate assets/generated/optimization/dqi automatically. No private execution driver, environment variable or kernel hook is required.

The coherent CPU component was validated at source commit 76fadb0b308ea4ea27a21382ca328d349314b1c4. These cells verify its saved hashes, signed amplitude law, quality, source ledger and original SVG. They do not repeat quantum simulation, sample outcomes, fit rotations or estimate physical resources. The normal generator separately materializes bounded inputs and emits a generation-only receipt; that receipt is not new coherent-validation evidence.

The saved default has n=3, m=4 and degree 1. Printed assignments are x2 x1 x0, with x0 the least significant integer bit. The objective counts satisfied binary equations. This small checked component is not a general optimization-advantage benchmark.

import importlib.util
import math
from fractions import Fraction
from pathlib import Path
from IPython.display import Markdown, display

cwd = Path.cwd()
candidates = (cwd, cwd / 'assets/generated/optimization/dqi', cwd.parent / 'assets/generated/optimization/dqi')
bundle = next((path for path in candidates if (path / 'verify_dqi_saved.py').is_file() and (path / 'bundle.json').is_file()), None)
if bundle is None:
    raise FileNotFoundError('Place this notebook beside the downloaded DQI bundle, or use the repository assets/generated/optimization/dqi directory.')
specification = importlib.util.spec_from_file_location('dqi_saved_public_verifier', bundle / 'verify_dqi_saved.py')
if specification is None or specification.loader is None:
    raise RuntimeError('Cannot load the supplied standard-library DQI saved-bundle verifier.')
verifier = importlib.util.module_from_spec(specification)
specification.loader.exec_module(verifier)
verified = verifier.verify_saved_bundle(bundle)
record = verified['record']
report = verified['verification']
assert report['status'] == 'saved_component_verified'
print('Portable saved DQI component and notebook-source projection verified.')
print('No quantum simulation, sampling, fitting, rotation synthesis or physical estimation is repeated.')

The clause vacuum and four singleton strings have equal positive amplitude 1/sqrt(5). The saved packet records signs, syndrome computation and coherent decoding with assignment support 0,1,2,4,7 and the last amplitude negative. The final Hadamards give amplitude (2 f(x) - 3)/sqrt(40). We check signed amplitudes as well as squared probabilities; positive square roots alone would miss the interference signs.

objectives = (3, 3, 3, 1, 3, 1, 1, 1)
numerators = (3, 3, 3, -1, 3, -1, -1, -1)
law = tuple(Fraction(n * n, 40) for n in numerators)
assert sum(law) == 1 and len(record['outcomes']) == 8
for i, outcome in enumerate(record['outcomes']):
    assert outcome['integer'] == i and outcome['bits'] == format(i, '03b')
    assert outcome['objective'] == objectives[i]
    assert abs(outcome['amplitude_real'] - numerators[i] / math.sqrt(40)) <= 2e-12
    assert abs(outcome['amplitude_imag']) <= 2e-12
    assert abs(outcome['probability'] - float(law[i])) <= 2e-12
expectation = sum(p * f for p, f in zip(law, objectives, strict=True))
success = sum(law[i] for i in (0, 1, 2, 4))
assert expectation == Fraction(14, 5) and success == Fraction(9, 10)
assert abs(record['quality']['expected_objective'] - float(expectation)) <= 2e-12
assert abs(record['quality']['maximum_draw_probability'] - float(success)) <= 2e-12
assert len(verified['table_lines']) == 10
display(Markdown(chr(10).join(verified['table_lines'])))
print(f'Ideal expected objective = {expectation}; maximum-objective draw probability = {success}.')

Limits and planned work¶

The bounded n<=3,m<=4,degree-one truth-table generator does not fulfill general large-DQI coverage. Scalable generators need real decoder promises, coherent preparation and matching synthesis, repetition, scoring/readout and physical resource accounting. The seven RY gates remain unsynthesized; 154 explicit T/T-dagger occurrences are not a complete compiled T demand or physical estimate. Full n=1/n=2 workflows have no separate numerical fixture in the saved pass. There is no local formal theorem, reproduced author benchmark, Native/factory run, GPU/remote run or hardware advantage result.

The portable bundle binds each notebook cell type and source. Ordinary execution may change outputs and execution counts without changing that source binding. Notebook execution status is established by its outputs and an execution receipt; the saved coherent-component evidence and generation-only receipts keep their separate scopes.
