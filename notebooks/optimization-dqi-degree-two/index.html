Degree-two graph DQI: saved C5 companion

This four-cell ordinary Python notebook reads a complete saved degree-two bundle. It authenticates file bindings and recorded component CLI exits, then displays the signed C5 reference, measured CPU-state diagnostics, and source/classical counts. It creates no circuit and repeats no state, matrix, angle, probability, generator or sampling computation.

This source template is unexecuted. It cannot substitute symbolic predictions for missing result files. The bundle needs the C5 source export, one bounded C5 validation component, the 24-wire figure-eight generation-only export and external zero-exit observations before the cells can complete. Notebook completion and publication acceptance remain separate.

C5 has five graph vertices and five edge clauses, but four gauge variables because vertex zero is fixed to zero. The prepared support contains weight-zero, one and two clause patterns. Its prefix counter, comparison flags and decoder scratch are cleaned before the final Fourier readout. The code is an affine/basis equivalent repetition-code toy, with an immediate linear-time classical optimum; no quantum advantage or physical-resource claim is supplied. The degree-one evidence remains separate.

from pathlib import Path
import hashlib
import json
import sys
import types
from IPython.display import Markdown, display

READER_SHA256 = "803ea2b04d1d5c141361cdebb98f7996b973e268625df340210d1d61042fed56"
candidates = (
    Path.cwd(),
    Path.cwd() / "assets/generated/optimization/dqi-degree-two",
    Path.cwd().parent / "assets/generated/optimization/dqi-degree-two",
)
bundle = next((path for path in candidates if (path / "bundle.json").is_file()
               and (path / "verify_dqi_degree_two_saved.py").is_file()), None)
if bundle is None:
    raise FileNotFoundError("Keep the complete degree-two saved bundle together, or run from its repository notebook directory.")
reader_path = bundle / "verify_dqi_degree_two_saved.py"
if reader_path.is_symlink():
    raise ValueError("The saved reader must be an ordinary file.")
with reader_path.open("rb") as stream:
    reader_source = stream.read((128 << 10) + 1)
if len(reader_source) > (128 << 10) or hashlib.sha256(reader_source).hexdigest() != READER_SHA256:
    raise ValueError("The pure saved-reader source differs from this notebook's frozen binding.")
reader = types.ModuleType("degree_two_saved_reader")
reader.__file__ = str(reader_path)
exec(compile(reader_source, str(reader_path), "exec"), reader.__dict__)
verified = reader.verify_saved_bundle(bundle)
report = verified["validation"]
print("Saved C5 checks and a figure-eight source export are authenticated. This notebook repeats no quantum work.")
print("Notebook source/type projection:", verified["notebook_source_projection_sha256"])

Recorded source and classical work¶

The generator’s actual primitive records include prefix-weight preparation, signs, reduced-incidence access, equality comparisons, target XORs, their inverses, all initial resets and assignment readouts. RY rotations remain unsynthesized. Classical graph/simple-graph/girth/code checks and sparse lookup construction are separately recorded. The displayed source totals are per draw. Classical scoring of measured cuts, retention of the best cut, complete-task repetitions, binary-RY synthesis and physical overheads are excluded from these totals. The saved analytic draw contract is shown separately; its prospective physical and factory budgets remain unmet, and no draws were sampled.

The figure-eight has nine graph vertices, ten edges and eight gauge variables. It remains a 24-wire generation-only example with no copied C5 probability, repetition or physical guarantee.

Saved cleanup and a primitive excerpt¶

The following diagnostics were captured during the same complete forward C5 pass. Preparation cleans the two-bit prefix counter and flag. Decoding clears the clause register and every equality-prefix scratch bit before the assignment Hadamards. The notebook reads these records without evolving any prefix or circuit again.

Logical register layout: clause/error wires 0–4; syndrome/assignment wires 5–8; shared clean workspace wires 9–11. The source stage order is reset, preparation, sign, syndrome, decoder, Hadamard and readout. The displayed forty-operation excerpt is only a prefix; the complete files are c5/circuit.qasm and c5/operations.ndjson, with the figure-eight export under figure-eight/.

The classical all-zero gauge cut scores zero. The alternating cut x4x3x2x1=0101 has four crossing edges, the maximum on an odd five-cycle. Each weight-two error has weight-three neighbors whose complements share their syndrome, so recovery of the prepared support supplies no every-neighbor/semicircle theorem premise. Neither the older degree-one results nor the frozen physical model is an advantage claim for this new task.
