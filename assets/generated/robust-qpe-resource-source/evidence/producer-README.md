# Robust-QPE quantum schedule

Source-only mode supplies actual primitive generators and design counts. Physical mode is bounded to one target, two dyadic levels and 400 trials per fringe. Its four fresh-preparation experiments run in one macrocycle repeated 400 times.

Physical totals cover this quantum schedule, including input preparation, literal controlled calls, resets, readout, protected workspace, actual synthesis and capped factory supply. Count aggregation, reliable classical storage, rational phase inference, calibration, communication and their extra idle exposure are excluded. No full end-to-end cost or hardware confidence is established.

The compiled checks use four tiny density evolutions and independent stored-angle fringes. They perform no shot sampling, phase recovery, complete population replay or formal proof. Guarded numerical synthesis is not an interval certificate for the robust probability promise. The existing baseline and records remain unchanged.

Original source is MIT. Use the included repository-shaped code snapshot with the existing Python 3.12.14 lock. Qiskit 2.6.2, its recorded rsgridsynth 0.2.2 backend and QDK 1.34.0 supply circuits, actual synthesis and the conditional factory model. The installed native-wheel identity limitation is retained in synthesis metadata.
