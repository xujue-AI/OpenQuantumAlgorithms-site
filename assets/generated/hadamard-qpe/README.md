# Hadamard phase estimation examples

Original MIT circuits, bounded numerical dyadic recovery and independent matrix/probability checks. Use the included Python3.12 requirements lock. Run the copied generator with --single --phase 0.3 --levels 6 and an explicit output directory. Default canonical study uses 48 circuit types and 47,376 modeled fresh trials. No Native estimation, hardware execution, synthesis certificate or Lean proof is included. See results.json for exact source hashes and ideal versus numerical confidence scope.
