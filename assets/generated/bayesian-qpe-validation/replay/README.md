# Original bounded Bayesian QPE artifacts

Explicit source circuits and posterior data accompany the fixed finite-grid method.
Credible cell arcs are model summaries, not uniform confidence or hardware certificates.
Resets, preparation, literal controlled powers and readout are counted; synthesis, physical reset/controller models and factories remain unavailable.
The known phase supplies only the pedagogical oracle and independent sampler/reference; it is not passed to experiment selection.
Use --source-only for larger circuits; those sizes have no dense validation or inference result.
