# Bounded HHL and Neumann physical sweeps

[Summary](summary.md), [CSV](summary.csv) and [manifest](manifest.json) retain actual complete-trial
circuits, independent reference fingerprints, fixed allocations, source hashes and conditional
surface-code reports. Use the included `code/` package and lock to reproduce them.

The target is 0.05 error with failure allocation 0.015 for each independent Z-mean task.
These allocations are conditional on an uncertified coherent-error interpretation of the
mean-fit synthesis scalar. No hardware output-confidence or simultaneous cross-grid guarantee
is claimed. All rejected complete attempts are charged. Fresh initialized-zero faults/timing,
classical construction/compilation/readout and hardware routing/decoder realization are excluded.
The structured families are not general input loaders or matched advantage benchmarks.
