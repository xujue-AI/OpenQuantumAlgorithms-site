Quantum algorithms, end to end

Quantum algorithm implementations

Circuits and resource estimates¶

Inspect a small working circuit, generate larger instances, and reproduce a resource estimate with its input assumptions and physical model.

Start with Grover’s search · Explore the roadmap

This project uses Quantum Algorithms: A Survey of Applications and End-to-end Complexities as a guide to algorithm coverage and end-to-end questions Dalzell et al., 2025. The explanations and implementations here are developed for this handbook; references identify the papers and software behind each example.

Publication status

This is an evolving handbook. Each listed family now has bounded working circuits and independent checks, with more general methods still marked planned. The examples include Fourier/phase and amplitude estimation, reversible order finding, structured linear systems, dynamics/open-system/thermal simulation and QAOA/VQE. The in-page resource sections distinguish computed logical workloads, conditional physical models and unimplemented layers.

Reading the book¶

Algorithms are listed directly in the table of contents. Each article brings together motivation and intuition, the fundamental algorithm and complexity, important variants, a small circuit, end-to-end resource analysis, and verification/formalization. These are sections of the algorithm page. Substantial methods such as QSP have a separate page under their parent chapter; notebooks remain executable companions. Physical estimates and incomplete methods are labeled explicitly.

The appendices introduce quantum physics, mathematics, and fault-tolerant computing. Reading and video links appear beside the concepts they support; videos are optional.

Download the public Python package, notebooks and tests to reproduce examples without accessing the private development repository.

What each implementation will provide¶

Understand the problem¶

An input and output contract, the access model, accuracy and success requirements, and a comparable classical task.

Inspect the circuit¶

A small reproducible circuit, a downloadable notebook, and code that generates larger instances.

Account for the resources¶

Logical circuit counts, compilation assumptions, and physical qubits and time under a named fault-tolerant model.

Check the evidence¶

Classical checks, cited implementations, and formal artifacts where a relevant verified development exists.

Run the examples¶

Grover’s search connects an explicit oracle to a circuit, simulated measurement probabilities, and logical operation counts. The companion notebook displays the saved results; its download is available in the page’s download panel.

The dynamics chapter and optimization chapter add checked circuits and complete-attempt or hybrid-workload records. Optimization has conditional model replays of recorded ideal paths; unsupported physical layers, including dynamic reset instruments, remain explicitly pending. QFT/QPE, order finding, linear systems and amplitude estimation have their own worked circuits and bounded resource reports.

Read the resource baseline before interpreting physical estimates, and verification for what each type of check establishes.

To run the notebook independently, save the generator beside it and install the pinned Python 3.12 environment:

python -m pip install -r requirements-lock.txt

The published original code and documentation are covered by the MIT license. Package licenses and attribution remain recorded with their implementations.

Open tools, attributed use¶

The first circuit implementation uses Qiskit. Later chapters will evaluate packages such as Qualtran, PennyLane, and Yao where their abstractions fit the task. Each adopted implementation will record its repository, license, version, and any modifications. The site is built with Jupyter Book 2 and the MyST Document Engine.
